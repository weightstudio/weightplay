Allez pêcher

Demandez à un adversaire une valeur que vous avez déjà. S’il la possède, il vous donne toutes ses cartes de cette valeur ; sinon, vous piochez.

Monde et mission

Go Fish transforme une petite main en table de mémoire et d’observation. Même une réponse négative fournit un indice sur une valeur.

Quand vous réunissez quatre cartes d’une valeur, le carré est compté puis retiré de votre main ; la fin demande de protéger les valeurs presque complètes.

Systèmes du jeu

Choisissez 2, 3 ou 4 joueurs et demandez uniquement une valeur déjà présente dans votre main.

Si l’adversaire l’a, il donne toutes ses cartes de cette valeur ; sinon vous piochez. Un carré complet est compté puis retiré.

Comment jouer

  1. Choisissez le nombre de joueurs, démarrez la table et observez vos valeurs.
  2. Sélectionnez un adversaire et demandez une valeur que vous avez ; voyez si la demande réussit ou mène à une pioche.
  3. Utilisez votre main mise à jour et les carrés complétés pour choisir la prochaine demande légale.
  4. Complétez les carrés de quatre et utilisez Recommencer ou Nouvelle partie pour rejouer.

Conseils

  • Mémorisez les valeurs demandées ou reçues par chaque adversaire ; un échec est aussi une information.
  • Quand les indices sont suffisants, demandez d’abord la valeur proche d’un carré.
  • Ne révélez pas trop tôt une valeur importante si un autre adversaire peut avoir la carte manquante.

Progression et difficulté

Chaque table est un défi complet de 13 valeurs avec 2, 3 ou 4 joueurs, sans progression de compte.

Chaque partie change la donne et les indices ; vous progressez en lisant le moment des demandes et en fermant les derniers carrés.

Note de conception

Go Fish réunit demandes, main, adversaires, pioche, valeur choisie et carrés complétés sur une table lisible.

Jeu public

Jouez gratuitement à Go Fish dans votre navigateur, sans compte ni achat. La table, les carrés, la progression et les préférences restent dans ce navigateur.

Questions fréquentes

Comment faire une demande ?
Choisissez un adversaire puis une valeur déjà dans votre main. Une valeur absente ne peut pas être demandée.
Que se passe-t-il si la demande réussit ?
L’adversaire donne toutes ses cartes de cette valeur et la table continue selon les règles.
Que se passe-t-il après Go Fish ?
Piochez une carte. Si elle complète un carré, il est compté ; sinon le tour passe.
Comment compléter un carré ?
Réunissez les quatre cartes d’une même valeur. Le carré est compté et retiré de votre main.
La progression est-elle sauvegardée ?
