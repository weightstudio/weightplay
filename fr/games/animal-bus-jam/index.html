Panko's Bus Jam

Read the convoy order, route each queue, and keep the holding lane from locking up.

How to play

Only the first bus accepts passengers. A wrong color waits in the holding lane, in order. If that lane blocks before the active bus is filled, the terminal deadlocks.

  1. Check the active bus and its remaining seats.
  2. Dispatch only the front passenger of a queue.
  3. Use Undo before the holding lane becomes blocked.

Panko's Bus Jam

Lisez l’ordre fixe des départs, révélez les bons passagers et empêchez la voie d’attente FIFO limitée de bloquer le terminal.

GenrePuzzle · Stratégie · Animaux
DifficultéFacile à exigeant
Temps estimé2 à 8 minutes par terminal

Monde et mission

Trente terminaux nocturnes fonctionnent à pleine capacité. Seul le bus actif peut prendre des passagers ; les autres couleurs attendent dans l’ordre exact d’envoi.

Toutes les décisions sont visibles : le convoi complet, chaque file, les places du bus actif et chaque emplacement occupé. L’échec vient d’un choix de route, pas d’un trafic caché ou d’un chronomètre.

Systèmes du jeu

Seul le premier passager de chaque file peut bouger. Un passager de la bonne couleur monte immédiatement dans le bus actif.

Un passager d’une autre couleur entre dans la voie d’attente. Il faut libérer son premier passager avant que ceux derrière puissent monter.

Quand le bus actif est plein, il part et le suivant devient actif. Les passagers correspondant au premier de la voie montent automatiquement.

Si la voie est pleine et qu’aucun passager visible ne peut terminer la route active, le terminal se bloque. Annuler restaure l’état exact précédent ; Recommencer restaure le terminal créé.

Comment jouer

  1. Choisissez un terminal déverrouillé.
  2. Lisez le bus actif, ses places restantes et les bus suivants du convoi.
  3. Comparez le premier passager de chaque file avant d’envoyer une couleur future dans la voie d’attente.
  4. Remplissez tous les bus sans bloquer la voie pour déverrouiller le terminal suivant.

Conseils

  • Considérez chaque place d’attente comme une ressource rare, pas comme un stockage gratuit.
  • Avant d’envoyer une couleur future, vérifiez si elle deviendra le blocage de tête.
  • Quand la voie est presque pleine, révélez d’abord la couleur active.
  • Utilisez Annuler dès qu’un envoi modifie l’ordre d’attente prévu.

Progression et difficulté

Le Terminal 1 enseigne le principe. À partir du Terminal 2, les mauvaises routes peuvent créer un vrai blocage.

Les chapitres suivants ajoutent une quatrième route, des convois plus longs, davantage de files et des couleurs répétées, avec une voie de deux places au lieu de répéter la configuration de trois bus.

Note de conception

Les quatre routes utilisent des codes de couleur et de lettres. Le convoi fixe, la voie FIFO, les files déterministes et la solution vérifiée forment un puzzle stratégique lisible sur téléphone et ordinateur. L’interface complète utilise une seule disposition logique centrée, limitée à 920 pixels. Le téléphone, le paysage et le bureau agrandissent ensemble les mêmes commandes, zones tactiles, illustrations et coordonnées du jeu, sans étirer les éléments séparément. Le tactile, la souris et le clavier agissent donc sur le même état valide. L’affiche de l’accueil et l’action de démarrage restent séparées de la gestion des niveaux ; la sélection de niveau, la bataille, les dialogues et le résultat gardent leur contenu borné et leur retour.

Note aux parents

Il s’agit d’un puzzle stratégique grand public sans limite de temps, compte, achat ni classement public. Les terminaux réussis restent dans ce navigateur. Vous pouvez jouer sans créer de compte. La progression est enregistrée dans le stockage local du profil actuel, pas dans un compte en ligne ni une base entre appareils. Effacer les données, utiliser la navigation privée, changer de navigateur ou d’appareil peut créer une autre sauvegarde ou supprimer l’actuelle. Lorsque le navigateur l’autorise, la langue, le son et la réduction des mouvements suivent les contrôles communs de WeightPlay. Le résultat du guide n’est pas une évaluation médicale, scolaire ou professionnelle.

Questions fréquentes

Puis-je envoyer un passager au milieu d’une file ?
Non. Seul le premier passager visible de chaque file peut bouger.
Pourquoi un passager est-il entré dans la voie d’attente ?
Seul le bus actif prend des passagers ; les routes futures attendent dans l’ordre d’envoi.
Pourquoi le terminal s’est-il bloqué ?
L’ordre d’attente bloquait la route active et aucun passager visible ne pouvait la libérer.
Tous les terminaux sont-ils solvables ?
Oui. Les trente parcours de solution enregistrés sont vérifiés automatiquement.
Quels contrôles et formats d’écran sont pris en charge ?
Les mêmes règles fonctionnent au tactile, à la souris et au clavier lorsque ces entrées sont disponibles. L’interface se redimensionne comme une seule disposition logique sur téléphone, paysage et bureau.
La progression se transfère-t-elle automatiquement vers un autre appareil ?
Non. Elle est actuellement enregistrée dans le navigateur ; un autre profil ou appareil aura sa propre progression.
