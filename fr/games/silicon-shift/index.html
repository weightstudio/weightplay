Comment jouer

Suis les entrées sur les pistes de cuivre. Une porte permute deux voies ; une charge de test montre où la lumière arrive.

Commandes et règles

Les repères de phase inversent les voyants après la porte. La sonde révèle les marques cachées. Respecte les liaisons et la limite de charge.

Terminer un service

Valide tous les cas avec le même câblage. Examine les sorties, réessaie gratuitement ou passe au service suivant. La progression reste dans ce navigateur.
