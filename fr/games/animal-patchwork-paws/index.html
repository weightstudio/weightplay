Comment jouer

  1. Ouvrez un morceau d’habitat et observez ses quatre bords colorés.
  2. Touchez les morceaux pour les tourner dans le sens horaire, puis vérifiez le tissage.
  3. Si les sentiers ne correspondent pas, utilisez le message calme ou réinitialisez le morceau.
