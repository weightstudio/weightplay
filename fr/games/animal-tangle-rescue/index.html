Sauvetage des lianes

Échange deux extrémités de liane jusqu’à relier chaque chemin au bon refuge.

Comment jouer
1

Lis les refuges

La ligne du bas indique l’animal attendu dans chaque refuge.

2

Échange deux extrémités

Touchez une extrémité puis une autre pour échanger leurs animaux.

3

Vérifie le sauvetage

Les bons chemins se relient ; les essais faux restent visibles.
