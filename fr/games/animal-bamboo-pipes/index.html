Comment jouer

  1. Choisissez un canal débloqué. Touchez un tuyau pour le tourner dans le sens horaire ; les ouvertures voisines doivent se rejoindre.
  2. Suivez le trajet de la source au parterre et repérez les raccords interrompus. Reliez le trajet pour débloquer le canal suivant.

Annuler revient sur la dernière rotation. Indice désigne un tuyau et son prochain raccord ; vous devez le tourner vous-même. Recommencer rétablit le puzzle. Rejouez pour réduire les rotations. La progression reste dans ce navigateur.

Questions fréquentes

Comment terminer un canal ?
Tournez les tuyaux jusqu’à aligner toutes les ouvertures voisines et relier la source au parterre.
