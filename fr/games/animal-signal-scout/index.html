Comment jouer

Six zones combinent ordre, inversion, postes endormis, mémoire et rotation. Lis les numéros et la règle, puis touche les lanternes animales. Sans chrono : tu peux revoir et corriger. Réussir sauvegarde et ouvre la suite.

  1. Lis à partir du numéro 1.
  2. Lis du dernier numéro vers le 1.
  3. Ignore les postes barrés.
  4. Mémorise, cache l’indice puis saisis le code.
  5. Déplace le premier poste à la fin.

Informations du joueur et sauvegarde

La vérification indique la première position incorrecte et conserve votre code. Supprimez une entrée ou effacez tout le code pour réessayer ; les patrouilles débloquées restent accessibles.

Les patrouilles débloquées et le meilleur nombre d’étoiles de chacune sont enregistrés uniquement dans ce navigateur si le stockage est disponible. Effacer les données du site supprime cette progression locale ; aucun compte ne la synchronise.

Questions fréquentes

Combien de patrouilles sont incluses ?
Il y a 30 patrouilles fixes réparties en six chapitres de cinq étapes, avec un point de contrôle toutes les cinq patrouilles. Les patrouilles terminées restent rejouables, y compris la trentième.
Que dois-je associer ?
Choisissez les signaux du renard, du hibou et du lapin selon l’indice numéroté et la règle : ordre direct, inverse, rotation, omission des postes endormis ou combinaison de règles.
Que se passe-t-il après un code erroné ?
La vérification indique la première position incorrecte et conserve votre code. Supprimez une entrée ou effacez tout le code pour réessayer ; les patrouilles débloquées restent accessibles.
L’ordre cible est-il caché ?
Les patrouilles ordinaires gardent l’indice visible. Dans celles de mémoire, étudiez puis masquez l’indice pour saisir le code. Vous pouvez le consulter à nouveau, mais cela compte comme une aide.
La progression est-elle sauvegardée ?
Les patrouilles débloquées et le meilleur nombre d’étoiles de chacune sont enregistrés uniquement dans ce navigateur si le stockage est disponible. Effacer les données du site supprime cette progression locale ; aucun compte ne la synchronise.
Puis-je jouer sur téléphone ?
Oui. Le tactile et la souris utilisent les mêmes commandes, et la mise en page s’adapte aux écrans portrait, paysage et ordinateur.

Jeux aux mécaniques proches

Simon — Hasbro

Simon demande de reproduire des séquences lumineuses aléatoires de plus en plus longues. Mémoriser un ordre est le défi commun, surtout dans nos patrouilles de mémoire, mais Signaux de patrouille ajoute des règles écrites à interpréter. Dans 30 patrouilles fixes, choisissez les signaux du renard, du hibou et du lapin : suivez ou inversez l’ordre, déplacez le premier élément à la fin ou ignorez les postes endormis. Les manches de mémoire permettent d’étudier puis de masquer l’indice. La vérification indique la première position incorrecte ; supprimez une entrée ou effacez le code pour réessayer. Les déblocages et les meilleurs nombres d’étoiles restent dans ce navigateur. Ce jeu solo n’est ni une édition officielle de Simon ni une connexion à un appareil Hasbro.

Il s’agit d’œuvres distinctes. Cette comparaison ne signifie ni version officielle, ni recommandation, ni partenariat.
