Guide du jeu

Une tuile est libre si rien ne la couvre et si au moins un côté est dégagé.

Clés des sceaux

Retirer une paire-clé ouvre ses sceaux. Annuler les referme.

Ordre des paires

Retirez les paires numérotées dans l’ordre indiqué. Les autres paires identiques ne sont pas soumises à cet ordre, mais leurs deux tuiles doivent tout de même être libres.

Indice

L’indice cherche une suite de coups pour vider le plateau dans une limite de recherche définie. Atteindre cette limite ne prouve pas que la partie est impossible.

Étoiles

Gagnez trois étoiles sans indice ni annulation. Une aide coûte une étoile ; les deux laissent une étoile. Rejouez pour améliorer votre record.

Niveaux

Videz le plateau pour débloquer le suivant parmi 30 niveaux. Les niveaux terminés restent rejouables. La progression est conservée dans ce navigateur si le stockage est disponible.
