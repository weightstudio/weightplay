Silicon Shift

Trace test pulses and wire one circuit to pass every case.

Game guide

Circuit puzzle
Shift · 60
Signal workshop
Phase lab

Goal

Make every output match its target.

How to play

Follow each input along the copper paths. Move a gate to exchange two lanes; use a test charge to see the actual output.

Controls and rules

Phase marks flip lights after the gate. A probe reveals hidden marks. Linked gates and power limits constrain the final wiring.

Finishing a shift

Verify with the same wiring for every case. Review the outputs, retry for free, or start the next shift. Progress stays on this browser.

News behind the game

Taiwan reported record monthly exports for October 2026. The game imagines a fictional test bench under rising demand.

Player and save information

Tap, click, or use Tab and Enter. There is no account; this browser saves clear records and panels. Clearing site data removes them. Panel purchases use earned diamonds and never change puzzle rules.
