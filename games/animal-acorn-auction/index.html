Acorn Auction — Game Guide

Read the woodland request, then select the single acorn lot that matches both its count and budget.

Game Overview and Mission

Acorn Auction is a short, deterministic woodland-market puzzle. You are the shopper responsible for matching each animal's request to one of three visible acorn lots. Every request has two conditions: an exact number of acorns and a maximum price in tokens. A lot is suitable only when it satisfies both. The animals are not competing bidders, and there is no hidden price or changing stock; the market is a setting for comparing the information on the cards. Your mission is to complete all three requests with valid choices. Success means every animal receives the requested quantity without exceeding its stated budget. Nothing is timed, and an incorrect choice does not end the run, so you can inspect the clues and make another decision.

How to Play and Complete Game Loop

  1. Choose Open the market, then select a request from the three-round map.
  2. Read the animal's exact acorn count and maximum token budget.
  3. Compare the count and price printed on all three lots.
  4. Choose the single lot that meets both conditions, then continue or revisit a round.

Each lot card shows its quantity and cost before you select it. “Exactly” applies to the number of acorns; “at most” means a price equal to the budget is allowed, while a higher price is not. A correct choice completes that request. A wrong choice adds one to the pick count and returns you to the same request after its feedback, without removing earlier completed requests. Start this round over resets the current request's picks so you can retry it. The Result after a request reports how many of the three requests are ready and how many picks that round took. Next request continues the authored sequence; the round map lets you choose another request. After all three are complete, the final Result shows the best fewest-picks total saved in this browser. There is no timer, life counter, purchase, or fail screen.

Progression and Difficulty

The game has three fixed requests, each with three lots and one answer that meets both clues. The Squirrel asks for exactly 3 acorns at no more than 5 tokens. The Rabbit asks for exactly 4 at no more than 6. The Otter asks for exactly 2 at no more than 7. Pressing Next request follows that order, but the map allows you to start or replay any request directly. The rules do not add a new mechanic or become timed later; the changing count-and-budget pairs are the progression. The later request may have a more generous budget even though it asks for fewer acorns, so price alone cannot reveal the answer. Difficulty comes from checking both numbers on every card rather than assuming the cheapest or largest lot is always right.

Practical Tips

  • Separate the two clues: first check the exact count, then check whether the price is within budget.
  • Compare all three cards; the cheapest lot can still have the wrong quantity.
  • A price equal to the stated maximum is allowed, but one token over is not.
  • After a miss, reread both values before trying again; the extra choice affects your pick count.
  • Use the round map when you want to revisit a request instead of following the sequence.

Developer Design Note

The requests use fixed numbers and show the relevant information on each lot, so a player can reason from visible rules rather than guess at odds or discover a hidden system. Quantity and price appear together because the intended decision is a two-check comparison: satisfying only one clue is not enough. The three authored combinations vary the answer position and the relationship between quantity and budget, while keeping the rule set small enough to learn in a short session. An incorrect lot returns to the same request and counts as another pick; it does not remove a life or spend time. That feedback makes a correction possible while keeping the final fewest-picks result meaningful. The round map supports focused replay, and Next request supports a continuous three-request run. The game uses ordinary buttons so the same choice model works with touch, mouse, and keyboard input. It has no auction timer, opponent bidding, upgrades, collectible economy, or random lot generation.

Player, Device, and Save Information

Play in a current browser on a phone, tablet, or computer. Tap a lot on a touch screen, click it with a mouse, or focus a native button and activate it from the keyboard. No sign-in, purchase, or other account feature is part of this game. Completed requests and the current attempt exist only in the open session. The best fewest-picks number is stored locally in this browser; clearing this site's browser data can remove that record. The game does not provide a cloud-save or cross-device progress feature.

FAQ

Does a lot need to match both clues?
Yes. It must contain exactly the requested number of acorns and cost no more than the listed budget. Meeting only one condition is not enough.
What happens after a wrong choice?
The pick is counted, feedback appears, and the same request becomes available again. Earlier completed requests remain complete; no life or timer is lost.
Can I replay a request I already finished?
Yes. Return to the round map and select any of the three requests. The map is available from the Result actions and does not lock completed requests.
What does “fewest careful picks” record?
It is the lowest total of lot selections for a completed three-request run. Wrong selections count too. The best number is kept in this browser, not in an online account.
Is the auction timed or multiplayer?
No. There is no countdown, competing bidder, online match, life limit, or spending system. The challenge is to compare each request with the three shown lots.
