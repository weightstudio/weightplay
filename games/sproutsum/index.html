Sproutsum

Plant each number so every row and column reaches its target.

Make a garden of true equations

Each number belongs to two crossing lines. Place the available tiles so all their totals agree.

How to play

Select a planting space, then a number in the tray. Each tile can be used only as many times as shown. Multiply and divide before adding or subtracting. Undo and Check are free.
