Code Breaker

World and Mission

Each stage presents a hidden four-color code drawn from a six-color palette. A submitted guess returns two different kinds of evidence: a color in the right slot, or a color that belongs in the code but sits in another slot. The board makes the distinction visible so the next guess can be reasoned from the previous one.

The campaign is arranged as six five-stage arcs. Signal School starts without repeated colors, Echo Chambers introduces repeats, Shadow Palette seals one color, Anchor Protocol fixes a slot, Pressure Vault reduces the guess budget, and Crown Cipher combines the later restrictions into a no-hint finish.

How the Systems Work

Build a four-color guess one slot at a time, then submit it to read exact-position and color-only feedback. The current stage controls the maximum guesses, whether colors may repeat, whether one palette color is unavailable, and whether a slot begins anchored.

Hint fills the first empty, non-anchored slot with its correct colour and spends one available hint; you still submit the guess. Undo removes the last submitted row and clears the editable slots, but does not refund hints. Restarting or replaying the stage restores its budgets and the same secret code.

Cleared stages and the highest unlocked stage are saved locally in this browser. The Result screen reports the stage outcome and offers the stage list, the next unlocked stage, or a replay.

How to Play

  1. Open Main and choose an unlocked stage from the 30-stage campaign rail.
  2. Read the arc rule before entering a four-color guess; it tells you whether repeats, a sealed color, an anchored slot, or a tighter guess budget applies.
  3. Submit a guess, separate exact-position clues from correct-color clues, and keep only deductions supported by the board.
  4. Use Hint when you need one safe next cell and Undo when a test guess no longer helps; neither tool chooses the whole code for you.
  5. Finish the stage, review Result, and choose Next Stage, Stages, or Replay to continue the campaign.

Strategy Tips

  • Start with a deliberate spread of colors when repeats are not allowed, then use exact-position clues to lock slots rather than changing the whole guess.
  • When repeats are enabled, count color-only clues carefully: one color may account for more than one position, so do not discard a duplicate too early.
  • Treat a sealed color as a deduction boundary and an anchored slot as fixed evidence; solve around the restriction instead of spending guesses against it.
  • Save the limited Hint for a stalled deduction, and use Undo to compare a theory without losing the stage's remaining budget.

Campaign and Difficulty Growth

Stages 1–5 teach exact positions and near colors without repeats. The next arcs add repeated colors, sealed palette options, anchored slots, fewer guesses, and finally a six-guess, no-hint combination of restrictions.

Every stage belongs to a fixed five-stage arc and unlocks in order. Replaying a cleared stage is useful for reducing guesses and learning the arc rule, while local progress keeps the next stage available.

Developer Design Note

Code Breaker keeps the hidden code small enough to reason about while making each constraint explicit. The 30-stage structure turns one familiar deduction loop into a readable progression: the board teaches evidence first, then asks the player to manage repetition, unavailable colors, anchored information, and shrinking resources. Keyboard, mouse, and touch use the same slot-and-color decisions, and the Result path returns directly to the campaign without an account or online service.

FAQ

What do the two clue types mean?
An exact-position clue means the color is in the correct slot. A correct-color clue means the color belongs in the code but is in another slot.
Can colors repeat?
Some arcs allow repeats and others explicitly do not. Read the current stage rule before deciding whether a duplicate is possible.
What does Hint do?
Hint fills the first empty, non-anchored slot with its correct colour and spends one available hint; you still submit the guess. Undo removes the last submitted row and clears the editable slots, but does not refund hints. Restarting or replaying the stage restores its budgets and the same secret code.
How does the campaign get harder?
Later arcs add repeated colors, a sealed color, an anchored slot, fewer guesses, and a final no-hint combination.
Is progress saved?
Cleared stages and the highest unlocked stage are saved only in this browser. No account is required.
Do the clue symbols identify particular code slots?
No. The numbers beside ● and ○ are totals for the whole guess, not labels for individual slots. For example, 0 ● and 4 ○ means all four colours, including their repeated occurrences, are present but in different positions. Keep that colour combination and test a different order, checking it against earlier rows too.
How are repeated colours counted?
Each occurrence in the secret can score only once. Exact matches are counted first, then misplaced matches use the remaining occurrences. In an illustrative repeat-allowed puzzle, secret A-A-B-C and guess A-D-A-A give 1 ● and 1 ○, not 1 ● and 2 ○. The extra A has no unused matching occurrence. Letters here stand for colours, not an actual stage answer.
Why can I not reuse a colour or edit a fixed slot?
Repeats are allowed only in stages 6–10 and 21–25; other stages reject a colour already in the guess. A sealed colour is unavailable and is excluded from the secret. Stages 16–20 fix slot 1, and stages 26–30 fix slot 2. Solve the remaining slots around that given colour rather than trying to remove it.
