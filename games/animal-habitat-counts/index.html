How to play

1. Read the clues

The numbers beside each row and below each column tell you how many cells should be filled.

2. Toggle cells

Tap a cell to fill or clear it. Every choice stays reversible.

3. Check the habitat

A wrong check shows the row and column counts; there is no timer or penalty.

Habitat pages

Each page uses the same row-and-column proof with a new habitat shape.
