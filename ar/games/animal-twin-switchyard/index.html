Twin Switchyard

Twin Switchyard هو لغز منصة متزامن أصلي. قم بتوجيه ثعالب الماء والماعز الجبلي عبر الممرات المنقسمة، واقلب بوابات الإشارة، واجمع كل شظايا التتابع معًا.

العالم والرسالة

يتشارك اثنان من حراس الطريق في خط إشارة واحد: يتولى ثعلب الماء التعامل مع المسار المنخفض بينما يسلك الماعز الجبلي المسار المرتفع. تطلب كل ساحة تبديل من كلا المسافرين التحرك خلال نفس اللحظة دون ترك أحدهما خلفهما.

كيف تعمل الأنظمة

يتقدم الحرفان من مدخل واحد مشترك. يحرك اليسار واليمين كلا المسافرين عبر الممرات المنفصلة الخاصة بهما، بينما يمنح الانتقال السريع كليهما قفزة محددة بوقت. يمكن للبوابة أن تفتح حارة واحدة وتغلق الأخرى، وبالتالي فإن المسار المفيد دائمًا ما يكون مشكلة تنسيق وليس تشغيلًا منفردًا.

يتم جمع أجزاء الترحيل فقط عندما يصل إليها المسافر الصحيح. يؤدي الاصطدام الخطر إلى إعادة ضبط محاولة المرحلة الحالية، بينما يتقدم المسار النظيف عبر كل جزء والخروج إلى النتيجة. يبقى تقدم المرحلة وأفضل عدد من التحركات المحلية في هذا المتصفح.

كيفية اللعب

  1. اختر مرحلة مفتوحة من Stage؛ واقرأ قاعدة المسار ومعاينة الخطر قبل الدخول إلى Battle.
  2. استخدم اليسار واليمين أو عناصر التحكم التي تظهر على الشاشة لترتيب كلا المسافرين، ثم استخدم الانتقال السريع لإزالة الخطر المحدد.
  3. راقب لون البوابة وحافظ على تحرك كلا المسافرين نحو أجزاء التتابع الخاصة بهم؛ يمكن أن تكون إحدى الشخصيات آمنة بينما تظل الأخرى مكشوفة.
  4. اجمع كل الشظايا واصل إلى المخرج المطابق. تعيد الاصطدامات المحاولة، بينما يفتح الإكمال Result والمرحلة التالية.

نصائح الاستراتيجية

  • قم بتخطيط الموضعين التاليين لكلا المسارين قبل الضغط على زر Jump؛ الهبوط الآمن لأحد المسافرين يمكن أن يشكل خطراً على الآخر.
  • استخدم صنابير الاتجاه القصيرة بالقرب من البوابات بدلاً من الاستمرار في تغيير المسار عبر ساحة التبديل بأكملها.
  • اقرأ علامات المسار العلوي والسفلي معًا. إن الجزء الأكثر وضوحًا ليس دائمًا هو الالتقاط الآمن التالي.
  • عندما تفشل المرحلة، حدد المسافر الذي وصل إلى الخطر أولاً واضبط التوقيت المشترك بدلاً من تغيير كل خطوة.

الحملة وصعوبة النمو

تبدأ ست مراحل مؤلفة بتقسيم واضح وقفزة متسامحة. تتضمن المراحل اللاحقة بوابات متناوبة، ومخاطر متحركة، وشظايا متداخلة، ونوافذ هبوط أضيق، ومجموعات تتطلب وصول كلا المسافرين إلى المخرج معًا.

مذكرة تصميم المطور

يحتفظ Twin Switchyard بمساحة لعب منطقية واحدة عبر الهاتف والمناظر الطبيعية وسطح المكتب. يتم حل حركتها المشتركة، والمخاطر الخاصة بالمسار، وأزرار اللمس، وتنشيط الماوس، وعناصر التحكم في لوحة المفاتيح إلى نفس الحالة، بينما تظل شاشات Main وStage وBattle وResult شاشات منفصلة مع عوائد مباشرة. The complete interface uses one centered logical layout with a 920-pixel maximum. Phone, landscape, and desktop views scale the same controls, hit areas, artwork, and game coordinates together instead of stretching individual pieces. Touch, mouse, and keyboard therefore act on the same legal state. The Main poster and Start Game action remain separate from Stage management, while Stage selection, Battle, dialogs, and Result keep their own bounded content and return path.

ملاحظة الوالدين

لا تحتوي لعبة المتصفح العامة هذه على حساب أو شراء أو دردشة أو لوحة صدارة أو تدفق إعلاني. يتم مسح المرحلة، ويظل أفضل عدد من التحركات واللغة والصوت والتفضيلات في ملف تعريف المتصفح الحالي ويمكن إعادة تعيينه عند مسح بيانات الموقع. You can play without creating an account. Progress is saved in local browser storage on the current browser profile, not in an online account or cross-device database. Clearing site data, using private browsing, changing browsers, or moving to another device can create a separate save or remove the existing one. Language, sound, and reduced-motion preferences follow the shared WeightPlay controls when the browser permits storage. No guide result is a medical, school, or professional assessment.

الأسئلة الشائعة

هل يستطيع المسافران التحرك بشكل مستقل؟
لا، فكل إدخال يحرك الزوجين معًا، وبالتالي فإن اللغز يدور حول التوقيت المشترك وتخطيط المسار.
ماذا تغير البوابة؟
تغير قاعدة البوابة المرئية المسار المفتوح أو الآمن في تلك اللحظة؛ قراءتها قبل الالتزام بالقفزة.
ما الذي يسبب مرحلة فاشلة؟
إذا لمس مسافر خطراً معلّماً أو خرج من المسار القابل للعب، تُعاد المحاولة الحالية إلى البداية.
هل التقدم ينقذ؟
تُحفظ المراحل المكتملة وأفضل عدد حركات محلي في هذا المتصفح.
Which controls and screen sizes are supported?
The same rules support touch, mouse, and keyboard where the game uses those inputs. The interface scales as one logical layout across the required phone, landscape, and desktop viewports.
Can progress move automatically to another device?
No. This game currently saves to local browser storage only, so another browser profile or device begins with its own separate local progress unless a future account system is added.
