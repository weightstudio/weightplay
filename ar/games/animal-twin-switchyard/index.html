ساحة مفاتيح التوأم

وجّه قضاعة وماعزًا جبليًا عبر مسارين منفصلين، وبدّل بوابات الإشارة، واجمع كل شظايا التتابع معًا.

طريقة اللعبSynchronized Platform Puzzle
النوعPuzzle · Platform · Animal
الصعوبةEasy to Challenging
الوقت التقريبي3-8 minutes per stage

القصة والهدف

Two route keepers share one signal line: the otter handles the low lane while the mountain goat takes the high lane. Each switchyard asks both travelers to move through the same moment without leaving one behind.

قواعد اللعبة

The two characters advance from one shared input. Left and Right move both travelers across their separate lanes, while Jump gives both a timed hop. A gate can open one lane and close the other, so the useful route is always a coordination problem rather than a solo run.

Relay shards are collected only when the correct traveler reaches them. A hazard collision resets the current stage attempt, while a clean route through every shard and the exit advances to Result. Stage progress and local best move counts stay in this browser.

كيفية اللعب

  1. Choose an unlocked stage from Stage; read the lane rule and hazard preview before entering Battle.
  2. Use Left and Right or the on-screen controls to line up both travelers, then use Jump to clear a marked hazard.
  3. Watch the gate color and keep both travelers moving toward their own relay shards; one character can be safe while the other is still exposed.
  4. Collect every shard and reach the paired exit. A collision restarts the attempt, while a clear opens Result and the next stage.

نصائح مفيدة

  • Plan the next two positions for both lanes before pressing Jump; a safe landing for one traveler can create a hazard for the other.
  • Use short direction taps near gates instead of holding a lane change through the whole switchyard.
  • Read the upper and lower lane markers together. The most obvious shard is not always the next safe pickup.
  • When a stage fails, identify which traveler reached the danger first and adjust the shared timing rather than changing every move.

تدرّج التحدي

Six authored stages begin with one clear split and a forgiving jump. Later stages add alternating gates, moving hazards, staggered shards, narrower landing windows, and combinations that require both travelers to arrive at the exit together.

ملاحظة التصميم

يحتفظ Twin Switchyard بمساحة لعب منطقية واحدة عبر الهاتف والمناظر الطبيعية وسطح المكتب. يتم حل حركتها المشتركة، والمخاطر الخاصة بالمسار، وأزرار اللمس، وتنشيط الماوس، وعناصر التحكم في لوحة المفاتيح إلى نفس الحالة، بينما تظل شاشات Main وStage وBattle وResult شاشات منفصلة مع عوائد مباشرة. تستخدم الواجهة الكاملة تخطيطًا منطقيًا واحدًا في المنتصف بحد أقصى يبلغ 920 بكسلًا. تعمل عروض الهاتف والوضع الأفقي وسطح المكتب على تغيير حجم عناصر التحكم ومناطق النقر والرسومات وإحداثيات اللعبة نفسها معًا بدلًا من تمديد العناصر منفردة. لذلك تعمل اللمسة والماوس ولوحة المفاتيح على الحالة القانونية نفسها. يبقى ملصق Main وإجراء بدء اللعبة منفصلين عن إدارة Stage، بينما يحافظ اختيار Stage وBattle والنوافذ الحوارية وResult على محتواها المحدود ومسار العودة الخاص بها.

ملاحظة للعائلة

لا تحتوي لعبة المتصفح العامة هذه على حساب أو شراء أو دردشة أو لوحة صدارة أو تدفق إعلاني. يتم مسح المرحلة، ويظل أفضل عدد من التحركات واللغة والصوت والتفضيلات في ملف تعريف المتصفح الحالي ويمكن إعادة تعيينه عند مسح بيانات الموقع. يمكنك اللعب من دون إنشاء حساب. يُحفظ التقدم في التخزين المحلي لملف المتصفح الحالي، وليس في حساب عبر الإنترنت أو قاعدة بيانات بين الأجهزة. قد يؤدي مسح بيانات الموقع أو استخدام التصفح الخاص أو تغيير المتصفح أو الانتقال إلى جهاز آخر إلى إنشاء حفظ منفصل أو إزالة الحفظ الحالي. عندما يسمح المتصفح بالتخزين، تتبع تفضيلات اللغة والصوت وتقليل الحركة عناصر تحكم WeightPlay المشتركة. لا تمثل أي نتيجة في الدليل تقييمًا طبيًا أو مدرسيًا أو مهنيًا.

الأسئلة الشائعة

Can the two travelers move independently?
No. Each input moves the pair together, so the puzzle is about shared timing and lane planning.
What does a gate change?
The visible gate rule changes which lane is open or safe at that moment; read it before committing to a jump.
What causes a failed stage?
A traveler touching a marked hazard or leaving the playable route resets the current attempt.
Does progress save?
Cleared stages and local best move counts are saved in this browser.
Which controls and screen sizes are supported?
The same rules support touch, mouse, and keyboard where the game uses those inputs. The interface scales as one logical layout across the required phone, landscape, and desktop viewports.
Can progress move automatically to another device?
No. This game currently saves to local browser storage only, so another browser profile or device begins with its own separate local progress unless a future account system is added.
