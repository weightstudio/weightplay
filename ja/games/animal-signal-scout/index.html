巡回信号合わせ

Signal Scout is a calm three-patrol decoding game. Read each scout note, match every animal with its coloured signal, and copy the visible patrol order to light the lookout. The complete session is short, deterministic, and designed so a player can understand the rule before making a choice.

世界とミッション

小さな展望ネットワークは、色付きの動物信号を使用して、松の尾根、小川の交差点、シダの掃除の間のパトロールを誘導します。偵察兵のメモは意図的にはっきりしています。各メモは動物とその色を示し、パトロールの順序はカードに表示されます。あなたの仕事は、その観察結果を正確でフレンドリーなコードに変えることです。

The game treats mistakes as information rather than punishment. A wrong code clears gently, keeps the note visible, and gives the player another chance without a timer, lives, purchase prompt, or threatening presentation. Finishing all three patrols completes one compact route through the lookout network.

ゲームの仕組み

各パトロールは、3匹の動物を3つの信号色にマッピングし、続いてターゲット順序を示すメモを提示します。シグナルカードには同じ動物のラベルが付いているため、プレイヤーは隠されたルールに頼ることなく、ノート、ターゲット、現在のコードを比較できます。

Tap or click cards to build the code in order. The visible Check code action compares the complete sequence with the target; Clear code removes the current attempt. Touch, mouse, and keyboard activation use the same patrol state and the same validation result.

The session tracks completed patrols and checks used. A best total may be stored locally in this browser when storage is available, but it never controls access, changes the puzzle, or sends progress to an account. Result offers a direct route back to the menu or to the patrol map.

遊び方

  1. Start from Main and choose the first open patrol, or use the patrol map to revisit a completed one.
  2. 偵察用メモを注意深く読み、名前の付いた各動物とペアになっている色を特定します。
  3. 表示されている巡回順序を見て、その順番で一致する動物の信号カードをタップします。
  4. コードを確認してください。間違っている場合は、メモを読み直してライフを失うことなくもう一度試すことができるように、試みはクリアされます。
  5. 3つのパトロールをすべて完了して結果の概要を確認し、メインに戻るか、別のパトロールを選択してください。

攻略のヒント

  • Treat the note as a small lookup table: say the animal first, then recall its colour and card label.
  • タップする前に、対象の注文を左から右に読み取ります。最初に計画を立てることで、偶発的な追加チェックを避けることができます。
  • コードが失敗した場合は、完全に新しいシーケンスを推測するのではなく、一度に1つの位置を比較します。
  • The order is always visible, so focus on careful matching rather than speed. There is no timer or life counter.
  • Use Clear code whenever you want a clean start; the game is designed for calm retries and local practice.

進行と難易度

Pine Lookoutは繰り返し動物を導入するので、プレイヤーは同じシグナルがコード内に複数回表示される可能性があることを学習します。

Creek Lookoutは、同じ読みやすいノートとカードのルールを維持しながら、動物のセットと順序を変更します。

Fern Lookoutは、3つ目の語彙セットでルートを完了します。3つのパトロールは一緒になって、マッピングの読み取りから一貫した適用までのコンパクトな進行を形成します。

開発者メモ

Signal Scout keeps the cognitive task visible in every screen: Main explains the promise, Stage names the patrol, Battle shows the note and target order together, and Result reports the completed count and checks. The responsive logical canvas preserves those relationships on portrait phones, compact landscape screens, and desktop widths. The game has no account, multiplayer, advertising, purchase, or timed-pressure flow.

プレイヤーと保存情報

Signal Scout is a General family browser puzzle for ages 6+; no account or purchase is required. Best checks and completed patrols stay only in this browser when local storage is available. Clearing site data can remove that local record, while every patrol remains playable.

よくある質問

パトロールは何回含まれていますか？
Three authored patrols make one short session: Pine Lookout, Creek Lookout, and Fern Lookout.
What do I match?
各偵察ノートを読み、すべての名前付き動物とその信号色をペアリングし、表示されているパトロール順序で動物をタップします。
What happens after a wrong code?
The code clears gently and the same note remains available for another try. No life, timer, or progress is lost.
ターゲットは隠されていますか？
いいえ。ターゲットの順序はバトルに表示されるため、チャレンジは目に見えない答えを暗記するのではなく、注意深く読んでマッチングすることです。
Is progress saved?
完了したパトロールとベストチェックの合計は、ストレージが利用可能な場合にのみこのブラウザに保存される可能性があります。
Can I play on a phone?
Yes. Touch and mouse input use the same controls, and the layout adapts to portrait, landscape, and desktop screens.
