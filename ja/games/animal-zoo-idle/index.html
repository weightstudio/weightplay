動物園おせわ

動物の世話や施設の強化をしながら、小さな動物園を育てる運営ゲームです。来園者が入園チケットを集める間に、飼育エリアを整え、新しい仲間を迎えましょう。30の里程標がすべて同じ園で並行して進み、数字付きのステージを選んだり解放したりする必要はありません。

世界とミッション

小さな門と数匹の動物から始まる草原の園を、プレイヤーが飼育係として少しずつ整えます。来園者を迎えるだけでなく、動物の幸福、居場所、施設の使いやすさにも気を配ります。

ミミやパンコたちは、園の成長を祝う里程標の確認に登場します。動物の世話や施設づくりを学び、同じ園を自分のペースで育てます。

ゲームの仕組み

来園者はチケットを集め、チケット箱に収入がたまります。里程標の報酬を受け取るたび、その後の収入に小さなボーナスが加わります。

「Tidy Habitat」は動物の幸福を上げ、「Enrichment Time」はチケットを得ます。二つの世話行動は短い共通クールダウンを使うため、今の目標に合わせて選びます。

門は8段階、スナックスタンド・展望デッキ・飼育係ステーションはそれぞれ4段階まで強化できます。動物の採用や施設の強化にはチケットを使います。

配置替えの目標では、草原の動物を別の位置までドラッグします。ボタンを押すだけでは達成になりません。動物、施設、里程標の進捗はこのブラウザに保存されます。

遊び方

  1. Start Gameを選ぶと、前回から続く同じ園に入ります。
  2. チケットを集めたり使ったりする前に、画面の目標をすべて読みます。
  3. 幸福が必要ならTidy Habitat、収入が必要ならEnrichment Timeを選びます。
  4. 目標に応じて門や施設を強化し、動物を迎え、草原で動物をドラッグして配置します。
  5. 達成した里程標はいつでも受け取れ、他の目標も同じ園で並行して進みます。

攻略のヒント

  • チケットを使う前に、動物数や施設の目標を確認しましょう。
  • 幸福を求める目標ではTidy Habitat、収入が足りない時はEnrichment Timeを選びます。
  • チケット箱を満杯のままにする目標では、達成するまで受け取らないでください。
  • 配置替えは動物を十分に離れた位置までドラッグします。

進行と難易度

30の里程標はチケット、動物の世話、配置替え、門の拡張、仲間の動物、施設の強化を扱い、後半はそれらの活動を組み合わせます。

すべての目標は同じ園で並行して進みます。Growth Reportには全目標が表示され、Battleのパネルは次に取り組みやすい里程標を案内します。

里程標を受け取っても、別の目標が解放されたり園がリセットされたりすることはありません。

開発者メモ

待つだけで進む放置ゲームではありません。里程標を通してチケット、動物の世話、配置替え、採用、施設強化を組み合わせます。数字付きのステージを進む形式ではありません。大きなボタンとドラッグ操作に対応し、戦闘や厳しい時間制限はありません。

保護者向け

チケットの使い方や動物の世話を話し合いながら、計画や順序を考える遊びに使えます。記録はゲーム内の進行情報で、学力や発達を評価するものではありません。Kids版に広告はなく、進行はこのブラウザに保存されます。

よくある質問

里程標はいくつありますか？
30個の里程標が同じ保存済みの園で並行して進みます。
Tidy HabitatとEnrichment Timeの違いは？
Tidy Habitatは動物の幸福を上げ、Enrichment Timeはチケットを与えます。両方に共通の短いクールダウンがあります。
動物の配置替えはどう達成しますか？
草原で動物を元の位置からはっきり離れた場所までドラッグします。
里程標を受け取ると園はリセットされますか？
いいえ。動物、門や施設の強化、ほかの里程標の進み具合はこのブラウザの保存に残ります。
進行状況は正式な能力テストですか？
いいえ。Growth Reportは園のゲーム内状況をまとめるだけで、正式な評価ではありません。
