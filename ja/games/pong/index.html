世界とミッション

下の緑色のラケットを操作します。サーブで開始。

ゲームの仕組み

コートをドラッグ、マウス移動、または ← / →（A / D）長押しで操作。自分の底線を抜かれると相手に1点。先に7点で勝利。

遊び方

  1. コートをドラッグ、マウス移動、または ← / →（A / D）長押しで操作。自分の底線を抜かれると相手に1点。先に7点で勝利。
  2. 中央で受けるとまっすぐ、端で受けると斜めに返ります。スペースでサーブまたは一時停止。

攻略のヒント

  • 中央で受けるとまっすぐ、端で受けると斜めに返ります。スペースでサーブまたは一時停止。

進行と難易度

相手ごとの勝利数を端末に保存します。3種類は対戦難度で、ステージ制ではありません。

開発者メモ

ボールの落下位置に合わせて左右に動きましょう。

プレイヤーと保存情報

相手ごとの勝利数、ベスト記録、サウンド設定はこのブラウザに保存されます。アカウント、購入、オンライン対戦は不要です。

よくある質問

パドルはどう動かしますか？
コートを左右にドラッグ、マウスを動かす、または ← / →（A / D）を長押しします。
得点はどう入りますか？
自分の底線をボールが抜けると相手に1点入り、先に7点を取った側が勝ちます。
パドルの端にはどんな役割がありますか？
中央で返すと直線的になり、端で当てると角度が変わって次の返球を難しくできます。
3つの難度は何を変えますか？
練習、クラブ、エキスパートはコンピューターの強さを変える対戦難度で、ステージではありません。
進行状況は保存されますか？
ベスト記録、勝利数、サウンド設定はこのブラウザに保存され、アカウントや購入は不要です。
