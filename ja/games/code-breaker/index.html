コードブレーカー

コードブレーカーは4枠の推理キャンペーンです。位置一致と色一致のヒントから秘密のコードを解き、30の作り込まれたステージを進みます。

ジャンルクラシック · パズル · ストラテジー

世界とミッション

各ステージでは6色のパレットから4色の秘密コードが作られます。推測を送ると、色と位置が一致する情報と、色は含まれるが位置が違う情報が分かれて返ります。その違いを読んで次の候補を絞ります。

キャンペーンは5ステージずつの6章です。重複なしから始まり、重複色、封印色、固定スロット、少ない推測数、最後はノーヒントの複合条件へ進みます。

ゲームの仕組み

4つの枠に色を入れて推測を送信します。章ごとに最大推測数、重複の可否、使えない色、開始時に固定された枠が変わります。

ヒントは固定されていない最初の空きマスに正しい色を入れ、残りヒントを1回消費します。回答の送信は自分で行います。元に戻す操作は最後に送信した行を削除し、編集可能なマスを空にしますが、ヒント回数は戻りません。同じステージをやり直すと回数制限が初期化され、秘密のコードは変わりません。

クリア済みステージと最高解放ステージはこのブラウザに保存されます。結果画面からステージ一覧、次のステージ、リプレイを選べます。

遊び方

  1. メインから30ステージのキャンペーンを開き、解放済みのステージを選びます。
  2. 推測する前に章のルールを読み、重複色、封印色、固定枠、推測数を確認します。
  3. 推測を送り、位置一致と色一致を分けて読み、盤面が支持する候補だけを残します。
  4. 詰まったらヒントで安全な1枠を確認し、仮説を比べるときは元に戻すを使います。どちらもコード全体を自動で解きません。
  5. ステージを終えたら結果を確認し、次のステージ、一覧、またはリプレイへ進みます。

攻略のヒント

  • 重複なしの章では色を広く試し、位置一致を使って枠を固定します。毎回4色すべてを入れ替える必要はありません。
  • 重複が許される章では色一致の数を丁寧に数ります。同じ色が複数枠に入る可能性を早く捨てないでください。
  • 封印色は推理の境界、固定枠は確定情報として扱い、残りの枠をその周りで組み立てます。
  • 限られたヒントは行き詰まった推理に残し、元に戻すで仮説を比較して推測数を守ります。

進行と難易度

最初の5ステージで位置一致と色一致を学びます。次の章では重複色、封印色、固定枠、少ない推測数が加わり、最後は6推測・ノーヒントの組み合わせになります。

各ステージは5つのまとまりで順番に解放されます。クリア済みを再挑戦して推測数を減らし、章のルールを身につけられます。

開発者メモ

コードブレーカーは秘密コードを4枠に絞り、制約を画面上で明確にします。30ステージは、証拠の読み方から重複、封印色、固定情報、限られた資源の扱いへと判断を広げます。キーボード、マウス、タッチは同じ枠と色の操作を使い、結果からキャンペーンへ戻れるため短い再挑戦がしやすくなっています。

プレイヤーと保存情報

コードブレーカーはブラウザで無料で遊べます。アカウント、購入、クラウド保存、オンライン対戦、広告の流れはありません。クリアしたステージ、到達した最も先の解放ステージ、サウンド設定はこのブラウザに保存され、サイトデータを消すと失われる場合があります。

よくある質問

2種類のヒントは何を意味しますか？
位置一致は色も枠も正しい情報、色一致はコードに含まれるものの枠が違う情報です。
色は重複しますか？
章によって異なります。重複できるかどうかをステージのルールで確認してください。
ヒントは何をしますか？
ヒントは固定されていない最初の空きマスに正しい色を入れ、残りヒントを1回消費します。回答の送信は自分で行います。元に戻す操作は最後に送信した行を削除し、編集可能なマスを空にしますが、ヒント回数は戻りません。同じステージをやり直すと回数制限が初期化され、秘密のコードは変わりません。
どう難しくなりますか？
重複色、封印色、固定枠、少ない推測数、最後のノーヒント条件が順に加わります。
進行状況は保存されますか？
クリア済みと最高解放ステージはこのブラウザだけに保存されます。
判定の記号は、どのマスが正しいかを示しますか？
いいえ。● と ○ の数字は回答全体の合計で、各マスへの印ではありません。例えば 0 ●・4 ○ は、重複分を含む4色の組み合わせは合っていて、位置は全て違うという意味です。色の組み合わせを保って並べ替え、以前の回答の判定とも照合しましょう。
重複した色はどう数えますか？
秘密のコードにある各色は、出現1回につき1回だけ対応できます。位置まで一致する色を先に数え、残りで位置違いを数えます。重複可能な例で、秘密が A-A-B-C、回答が A-D-A-A なら 1 ●・1 ○ です。1 ●・2 ○ ではありません。余分な A に対応する色が残っていないためです。文字は色の代用で、実際のステージの答えではありません。
同じ色を選べない、固定マスを変更できないのはなぜですか？
重複色を使えるのはステージ6–10と21–25だけです。それ以外では回答にある色を再び選べません。封印された色は選べず、秘密のコードにも含まれません。16–20は1番目、26–30は2番目のマスが固定されます。その色を既知の条件として残りを推理しましょう。
