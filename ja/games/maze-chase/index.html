メイズチェイス

メイズチェイスは、固定迷路で星のかけらを集めるオリジナルゲームです。オルラを3つのステージへ導き、4種類のウィスプの追跡パターンを読み、ビーコンで危険な通路を短い反撃の機会に変えます。

世界とミッション

月明かりのアーカイブは、毎回ランダムに変わる盤面ではなく、読みやすい1つの迷路でできています。各ステージは通路の感覚を保ちながらウィスプの開始位置と圧力を変えるため、ルート知識が役立ちますが、丸暗記だけにはなりません。

4種類のウィスプは、直接近づく、現在の進行方向を予測する、次の曲がり角の先を狙う、開いた道をさまようという異なる動きをします。役割マーカーで危険の種類を見てから通路を選べます。

ゲームの仕組み

矢印キーまたは WASD でオルラを通路1マスずつ動かします。タッチでは画面の方向パッドか迷路のスワイプを使い、同じルート判定を共有します。

ステージを終えるには星のかけらをすべて集めます。ビーコンを取ると短いパワー時間が始まり、逃げるだけでなくウィスプを追って得点できます。

衝突するとライフを1つ失い、現在のルート上で位置が戻ります。ライフが尽きるまでステージは続くため、ミスは即時終了ではなく次の判断材料になります。

スコア、ベスト、ステージ、ライフ、サウンド、リスタート、離脱確認、成功・失敗後の結果復帰は同じランの流れに含まれます。ベストはこのブラウザーにだけ保存されます。

遊び方

  1. Main から開始し、最初の通路の出口を見てから方向を選びます。
  2. 小さな星を集めながら、逃げ道になる曲がり角を1つ残します。
  3. ウィスプの役割マーカーを読み、安全な選択肢をすべて消す通路には入らないようにします。
  4. 追跡が近くなったらビーコンを取り、パワー時間に向きを変えてウィスプを追います。
  5. 3ステージをクリアしてルートを終えるか、リスタートで現在の開始位置を練習します。

攻略のヒント

  • 最も深い通路へ最初から入らず、ウィスプが近づいたときに方向を変えられる曲がり角を残します。
  • 直接追うウィスプで早めの旋回を覚え、予測型と待ち伏せ型の道を見てからビーコンを取ります。
  • 離れた星へ直行するより、近い星を2つ取れる安全な迂回の方が得になることがあります。
  • 複数のウィスプが見える混雑した分岐でビーコンを使うと、反転によって得点と空間を同時に作れます。
  • 衝突後の短い無敵時間に次の通路を読み直し、同じ曲がり角をそのまま繰り返さないようにします。

進行と難易度

ステージ1は遅いウィスプで収集と通路の読み方を教えます。

ステージ2はウィスプの開始位置を変え、追跡速度を上げるため、より早いルート判断が必要です。

ステージ3は同じ固定迷路に最も強い圧力を重ね、ビーコンのタイミング、短い迂回、落ち着いた復帰を試します。

よくある質問

ステージをクリアするには？
ビーコンのあるマスも含め、固定迷路の収集物がある全マスを通ります。残りの収集物がゼロになるとステージクリアです。追加得点のためにウィスプを追う必要はありません。
ウィスプは同じ追跡ロジックですか？
いいえ。直接型、予測型、待ち伏せ型、徘徊型は異なるルートを選び、別々の役割マーカーを表示します。
ビーコンは何をしますか？
近くのウィスプを追ってボーナスを得られる短いパワー時間を始めます。
衝突するとどうなりますか？
ライフを1つ失い、短い無敵時間付きで現在のルートへ戻ります。ライフが尽きるまでステージは続きます。
スマートフォンで遊べますか？
はい。迷路をスワイプするか画面の方向パッドを使えます。デスクトップでは矢印キーと WASD も使えます。
進行状況は保存されますか？
ベストスコアとサウンド設定だけがこのブラウザーに保存され、アカウントは必要ありません。
