NIGHT TERMINAL CONTROL

パン子のバスジャム

Read the convoy order, route each queue, and keep the holding lane from locking up.

How to play

Only the first bus accepts passengers. A wrong color waits in the holding lane, in order. If that lane blocks before the active bus is filled, the terminal deadlocks.

  1. Check the active bus and its remaining seats.
  2. Dispatch only the front passenger of a queue.
  3. Use Undo before the holding lane becomes blocked.

世界とミッション

30か所の夜間ターミナルが満員で稼働しています。乗客を乗せられるのは現在のバスだけで、ほかの色は送った順に待機レーンで待ちます。

すべての判断材料が見えています。車列全体、各列、現在のバスの空席、埋まった待機枠を確認できます。失敗は隠れた交通やタイマーではなく、ルートの選択から起こります。

ゲームのしくみ

各列で動かせるのは先頭の乗客だけです。同じ色の乗客はすぐ現在のバスに乗ります。

色が違う乗客は待機レーンに入り、その先頭を出すまで後ろの乗客は乗れません。

現在のバスが満席になると出発し、次のバスが現在の目標になります。待機レーンの先頭が同じ色なら自動で乗車します。

待機レーンが満杯で、見えている乗客から現在のルートを完成できないとターミナルが詰まります。「戻す」は直前の状態を復元し、「やり直す」はステージを初期化します。

遊び方

  1. 解放済みのターミナルを選びます。
  2. 現在のバス、空席、車列の次のバスを確認します。
  3. 先の色を待機レーンへ送る前に、各列の先頭を比べます。
  4. 待機レーンを詰まらせず全バスを満席にして、次のターミナルを解放します。

攻略のヒント

  • 待機枠は無料の収納ではなく、限られた資源として扱いましょう。
  • 先の色を送る前に、それが先頭の詰まりになるか確認します。
  • 待機レーンが満杯に近いときは、現在の色を先に見えるようにします。
  • 送り出した乗客で考えていた待機順が変わったら、すぐ「戻す」を使います。

進行と難易度

ターミナル1で流れを学び、2以降では間違ったルートが本当の詰まりを生みます。

後半は4路線、長い車列、多い列、同じ色のバスを追加し、固定3台構成ではなく2枠の待機レーンを使います。

デザインノート

4つのルートは色と文字コードを併用します。固定車列、FIFO待機レーン、決定的な列、検証済みの解答が、スマートフォンでもデスクトップでも読みやすい戦略パズルを作ります。完全な画面は中央寄せの単一論理レイアウトで、最大幅は920ピクセルです。スマートフォン、横画面、デスクトップでも操作、タップ領域、アート、ゲーム座標を一緒に拡大縮小し、個別には引き伸ばしません。そのためタッチ、マウス、キーボードは同じ合法状態を操作します。メインのポスターと開始操作はステージ管理から分離され、ステージ選択、バトル、ダイアログ、リザルトはそれぞれの範囲と戻り道を保ちます。

保護者の方へ

アカウント、購入、公開ランキングのない、一般向けで時間制限のない戦略パズルです。クリア状況はこのブラウザだけに保存されます。アカウントなしで遊べます。進行状況は現在のブラウザプロフィールのローカルストレージに保存され、オンラインアカウントや端末間データベースには保存されません。サイトデータの削除、プライベートブラウズ、ブラウザや端末の変更で別のセーブが作られたり、現在の進行が消えたりすることがあります。保存が許可される場合、言語、サウンド、動きを減らす設定は WeightPlay 共通コントロールに従います。ガイドの結果は医療、学校、専門的な評価ではありません。

よくある質問

列の途中から乗客を送れますか？
いいえ。見えている各列の先頭だけを動かせます。
なぜ乗客が待機レーンに入ったのですか？
乗れるのは現在のバスだけで、ほかのルートは送った順に待つからです。
なぜターミナルが詰まったのですか？
待機順が現在のルートを塞ぎ、見えている乗客から解消できなかったためです。
すべてのターミナルは解けますか？
はい。30本の解答ルートはすべて自動検証されています。
対応する操作と画面サイズは？
タッチ、マウス、キーボードを使える場所では同じルールで遊べます。指定のスマートフォン、横画面、デスクトップで単一の論理レイアウトが拡大縮小します。
進行状況は別の端末へ自動で移りますか？
いいえ。現在はブラウザ内だけに保存され、別のプロフィールや端末には別の進行状況ができます。
