Paciência Yukon

Yukon Solitaire distribui o baralho completo em sete colunas do tabuleiro. Construa sequências rubro-pretas descendentes, mova qualquer grupo elegível com a face para cima e complete quatro bases de naipes sem estoque.

Mundo e Missão

Yukon mantém todas as 52 cartas na mesa, mas afrouxa a regra do grupo: qualquer carta virada para cima pode carregar todas as cartas viradas para cima abaixo dela. Essa liberdade cria revelações dramáticas, mas também torna preciosas as primeiras colunas vazias.

O jogo recompensa a exposição rápida de cartas viradas para baixo, ao mesmo tempo em que escolhe quando usar um movimento de grupo flexível e quando preservar um espaço de aterrissagem do Rei.

Como funcionam os sistemas

O quadro usa sete colunas com uma seção voltada para baixo e uma seção voltada para cima. Construa sequências descendentes de cores alternadas.

Ao contrário do FreeCell ou Klondike, qualquer carta virada para cima pode iniciar um movimento com todas as cartas viradas para cima abaixo dela, mesmo que esse grupo não seja uma sequência completa.

Colunas vazias aceitam apenas um Rei ou um grupo começando com Rei. As fundações são construídas de acordo com o naipe do Ás ao Rei.

Não há estoque. A dica destaca um movimento legal e Desfazer restaura o quadro completo e o estado fundamental.

Como jogar

  1. Selecione uma carta exposta ou qualquer grupo virado para cima.
  2. Mova-a para o próximo nível mais alto da cor oposta ou coloque uma única carta elegível em sua Fundação.
  3. Exponha as cartas viradas para baixo limpando suas cartas de cobertura.
  4. Use uma coluna vazia somente quando um grupo liderado pelo Rei puder ocupá-la.
  5. Complete todas as quatro bases de naipes para vencer.

Dicas de estratégia

  • Exponha as cartas viradas para baixo antes de fazer alterações apenas na superfície.
  • Trate uma coluna vazia como uma reserva King, não apenas como espaço livre.
  • Use grupos arbitrários virados para cima para revelar cartas ocultas, mas não deixe uma carta inferior útil.
  • Mova Ases e cartas de base baixa quando elas abrirem uma coluna ou desbloquearem uma carta virada para baixo.
  • Use Desfazer para comparar um movimento de grupo em negrito com uma rota de revelação mais lenta.

Campanha e crescimento de dificuldade

Cada distribuição usa todas as 52 cartas do tabuleiro e não tem fase de estoque.

As primeiras rodadas ensinam a diferença entre mover uma sequência e mover qualquer grupo virado para cima.

O maior desafio vem da preservação do espaço de pouso e do planejamento de múltiplas revelações futuras.

Nota dos pais

Yukon Solitaire é um jogo de estratégia de cartas para o público em geral, recomendado para maiores de 9 anos e para jogos em família. Nenhuma conta é necessária; as preferências permanecem neste navegador.

Perguntas frequentes

Existe um estoque?
Não. Todas as 52 cartas começam no tabuleiro.
Qualquer grupo virado para cima pode se mover?
Sim. Qualquer carta virada para cima pode conter todas as cartas viradas para cima abaixo dela.
O que pode preencher uma coluna vazia?
Um Rei ou um grupo cuja primeira carta é um Rei.
Os naipes do tableau se alternam?
Sim. As compilações do Tableau são descendentes por classificação em cores alternadas.
Posso desfazer?
Sim. Desfazer restaura todo o quadro e fundações anteriores.
