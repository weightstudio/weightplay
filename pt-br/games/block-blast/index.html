Como jogar

  1. Arraste uma das três formas fixas para o tabuleiro 8×8.
  2. Uma prévia elevada e translúcida mostra uma posição válida.
  3. Complete uma linha ou coluna para apagar imediatamente.

As formas não podem mover nem girar depois. Linhas completas somem na hora.

Nenhuma forma restante cabe.

Perguntas frequentes

As formas podem girar?
Não. Cada formato de bandeja mantém sua orientação exibida.
Quando os pontos aumentam?
Somente linhas ou colunas preenchidas concedem pontos; simplesmente colocar uma forma não.
Quantas fases há?
Existem 30 missões de campanha de autoria, além de uma corrida infinita ilimitada.
O que o gelo e a pedra fazem?
O gelo permanece visível abaixo de um bloco colocado até que sua linha seja eliminada; a pedra não pode ser ocupada.
Por que a corrida terminou?
A execução termina quando nenhuma das formas não utilizadas na bandeja atual tiver um posicionamento legal.
O progresso é salvo?
Os desbloqueios e preferências de campanha são armazenados localmente neste navegador.
Quais controles e tamanhos de tela são compatíveis?
Quando o jogo oferece suporte, toque, mouse e teclado seguem as mesmas regras. A interface se adapta como um único layout lógico nos tamanhos necessários de celular, paisagem e desktop.
O progresso é transferido automaticamente para outro dispositivo?
Não. Atualmente, este jogo salva o progresso apenas no armazenamento local do navegador, então outro perfil de navegador ou dispositivo terá um progresso local separado, a menos que um sistema de contas seja adicionado no futuro.
