How to play

1. Choose a stone

Tap a moonstone, then drag it toward a dock.

2. Watch the link

The other stone shifts with the same drag, by pull or push.

3. Check the pair

Both stones must sit on their glowing docks. A wrong try stays visible.

Read the whole meadow

The meadow contains thirty authored docks arranged in six arcs, so the map is more than a list of repeated puzzles. Begin with the first ready card and read its target pair before moving anything. The target names the final dock for every moonstone, while the relation badge explains how linked stones respond. A completed dock unlocks the next card and remains replayable. Checkpoints at docks 5, 10, 15, 20, 25, and 30 mark meaningful changes in the campaign. Your progress is stored only in this browser, and there is no timer, life counter, ranking, purchase, or penalty for experimenting. When you return later, the map shows completed and ready cards so the next useful action is visible immediately. Use Meadow map from Main whenever you want to choose an unlocked dock instead of restarting the campaign. Result offers the next dock, the map, and a return to Main, making every play session easy to continue or stop voluntarily.

Plan for changing links

Early docks teach the basic pull and push relationships. With pull, the linked partner follows the selected stone's direction; with push, it responds in the opposite direction. Later arcs add polarity flips, fixed anchors, blocked docks, and three-stone chains. Read the mechanic label and inspect the numbered rail before dragging. An anchored stone does not move, a blocked dock cannot receive a stone, and chain partners may travel different distances. These rules are always represented on the active board; there is no hidden exact-cell answer. Start by comparing the current positions with the target, choose the stone whose linked response helps both pieces, and prefer a move that improves more than one final position. If a move creates a collision or tries to use a blocked destination, the game rejects it without consuming a life. The numbered rail remains physically left-to-right even in Arabic, so Dock 2 means the same visible location in every language.

Check, recover, and improve

After moving the stones, use Check the pair only when every visible position matches the target card. Success opens a truthful Result and records the dock as complete. If the pair is not aligned, the current arrangement stays on screen so you can compare it with the target and revise one decision instead of guessing from a blank board. Reset positions restores the authored starting arrangement and clears the move count for that attempt. There is no advantage to rapid input: watch the linked response settle, then decide whether the next move should act on stone A, stone B, or a free member of a chain. Try to explain why each move helps before releasing it. Your best completed campaign total is saved locally, but a higher move count never blocks progress. Replay an unlocked dock to practise a cleaner route, use the map to switch challenges, or return to Main to reread these rules. A good run is one where you understand the relation and can predict the partner's response, not merely one where you finish quickly.
