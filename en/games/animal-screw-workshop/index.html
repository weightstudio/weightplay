Animal Screw Workshop

Animal Screw Workshop is a thirty-puzzle spatial logic game led by Gear Horn Rux. Move each brass screw into an open hole, release every layered wooden animal plate, and repair the forest workshop within the shown move limit.

World and Mission

The forest workshop's carved animal signs have become fastened into tangled stacks. Rux needs the player to free each plate without using up the few safe buffer holes. Completing a puzzle restores one sign, and clearing all six chapters reopens the whole workshop.

How the Systems Work

Select one unlocked screw and then an empty hole. A plate falls as soon as none of its support holes still contains a screw. Shared fasteners can hold several plates, while locked screws become available only after enough upper layers have fallen.

Every puzzle has a fixed layout and move limit. Undo restores the complete previous move, Restart rebuilds the same puzzle, and Hint highlights one safe screw-and-hole route without playing it. Efficient clears award up to three stars and unlock the next puzzle.

How to Play

  1. Choose an unlocked brass screw.
  2. Choose an open hole that can safely hold it.
  3. Release all wooden animal plates before the move limit.
  4. Use Undo, Restart, or Hint when a route closes.

Strategy Tips

  • Keep at least one buffer hole available for the next layer.
  • Check which plates share a screw before moving it.
  • Remove upper plates first when they unlock lower fasteners.
  • Use Undo as soon as a move blocks every safe destination.

Campaign and Difficulty Growth

Puzzles 1-5 teach basic relocation; 6-10 add overlapping plates; 11-15 introduce shared fasteners; 16-20 add locked screws; 21-25 tighten the available routes; 26-30 combine every rule into multi-layer release chains.

Developer Design Note

The game uses deterministic support rules instead of random physics, so every move can be planned from visible information. The two-step screw-and-hole input works with touch, mouse, and keyboard. Short falling animations explain the result without deciding it, and the responsive board keeps every interactive hole visible on phone and desktop.

Parent Note

This Kids puzzle is ad-free and requires no account. Puzzle progress, stars, best moves, and the chosen language stay in the current browser and are not uploaded. It is a recreational logic game, not a formal ability assessment.

FAQ

How many puzzles are included?
Thirty deterministic puzzles across six chapters.
Why did a plate fall?
All screw holes supporting that plate became empty.
What is a locked screw?
It becomes movable after enough upper plates have been released.
Does Hint make a move?
No. It only highlights one safe screw and destination.
What does Undo restore?
It restores screw positions, fallen plates, and the move count before the last move.
Is progress saved?
Yes, only in this browser.
Is an account required?
No.
Does the game contain ads?
No. This Kids game is ad-free.
