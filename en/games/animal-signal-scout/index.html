How to play

Work through 30 fixed patrols in six chapters. Each note shows the animal order and a rule: read forward or backward, move the first post to the end, skip crossed-out posts, or combine rules. Every fifth patrol is a checkpoint; later chapters add memory and mixed-rule routes. Check marks the first wrong position without erasing your entries. Clear a patrol to save its best star rating and open the next one; cleared patrols remain replayable.

  1. Read numbered posts from 1 onward.
  2. Read the posts from the last number back to 1.
  3. Skip every crossed-out sleeping post.
  4. Study the posts, then hide them and enter the code.
  5. Move the first post to the end, then read the order.

Player and Save Information

Check marks the first incorrect position and keeps your code. Remove an entry or clear the code to try again; unlocked patrols are not lost.

Unlocked patrols and each patrol’s best star rating are saved only in this browser when storage is available. Clearing site data removes that local progress; there is no account sync.

FAQ

How many patrols are included?
There are 30 fixed patrols in six five-stage chapters, with a checkpoint every fifth patrol. Cleared patrols, including Patrol 30, remain replayable.
What do I match?
Match the fox, owl and rabbit signals using the numbered clue and the stated rule: forward, reverse, rotation, skipping sleeping posts, or a combination.
What happens after a wrong code?
Check marks the first incorrect position and keeps your code. Remove an entry or clear the code to try again; unlocked patrols are not lost.
Is the target hidden?
Ordinary patrols keep the clue visible. In memory patrols, study the clue, hide it to enter your code, and review it again when needed. Reviewing counts as a hint.
Is progress saved?
Unlocked patrols and each patrol’s best star rating are saved only in this browser when storage is available. Clearing site data removes that local progress; there is no account sync.
Can I play on a phone?
Yes. Touch and mouse input use the same controls, and the layout adapts to portrait, landscape, and desktop screens.
How are patrol stars earned?
A first-check clear with no clue review earns three stars. A clear within three checks earns two; later clears earn one. Reviewing a memory clue counts as a hint, so it rules out a three-star clear for that patrol.
