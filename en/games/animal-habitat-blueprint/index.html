    Swap four habitat tiles to satisfy every neighbour clue and build a calm, connected home for the animals.

    How to play Habitat Blueprint

    Each stage presents four habitat tiles and three field notes. Read every note before moving anything, select two tiles, and use Swap selected to exchange their positions. A correct layout satisfies all three notes at the same time. An incorrect exchange does not end the stage, so you can inspect the new arrangement, choose another pair, or reset the blueprint and begin again.

    1. Read all three field notes and identify the habitats named by more than one clue.
    2. Select exactly two tiles, check their highlighted positions, and swap them.
    3. Keep testing the combined clues, or reset safely when a trial arrangement is not useful.

    Understand the field notes

    A “must touch” note means the two named tiles need to share an edge; a corner alone is not enough. A “must not touch” note rules out any shared edge. A “sits below” note fixes one habitat in the lower row and the other directly above it in the same column. Treat these notes as one connected system. A tile that satisfies one note can still violate another, so confirm the complete board after every swap.

    Thirty stages across six chapters

    The campaign contains 30 stages arranged in six chapters of five. Early blueprints allow free exchanges while you learn the three clue types. Later chapters restrict which positions can trade places, introduce diagonal exchanges, anchor one habitat so it cannot move, and add a four-swap budget. The final chapter combines an anchored tile with diagonal movement. Every fifth stage is a checkpoint, giving the campaign a steady rhythm without changing the core goal.

    A reliable solving method

    Start with the strongest clue. A below relationship determines both a row and a column, so it usually narrows the board more than a simple neighbour clue. Next, place any pair that must touch, then use the forbidden pair to choose between the remaining orientations. In restricted chapters, study which swaps are legal before committing. If a habitat is anchored, solve around it; if only diagonal swaps are available, picture the board as two crossing pairs.

    You do not need to chase the lowest swap count on the first attempt. Solve the layout cleanly, learn why it works, and replay if you want a better result. When a trial makes the board harder to read, Reset plan restores the stage’s starting arrangement without affecting cleared stages. The on-screen notes remain visible throughout the attempt, so there is no need to memorize them.

    Controls, feedback, and recovery

    Use a mouse, trackpad, or touch screen to select tiles. The selection status names the chosen habitats, and Swap selected becomes available after two valid choices. Feedback explains whether the completed arrangement fits every field note. You can return to the stage map from an active blueprint; the confirmation explains that the current arrangement will be discarded while previously cleared stages remain saved. Sound can be turned on or off from Settings.

    Results and local progress

    Completing a blueprint records that stage as cleared and updates the campaign’s best swap count. From the result panel you can continue to the next stage, replay the current one, or return to the stage list. Cleared stages and best results are stored locally in this browser rather than in an online account. Clearing browser storage, using private browsing, or moving to another browser or device can remove that local progress.

    Practical tips

    • Translate every note into a position rule before making the first swap.
    • Use the below clue first when it identifies an exact vertical pair.
    • After each move, verify all three notes instead of only the clue you targeted.
    • In budget stages, avoid exploratory swaps and use Reset plan when the route is no longer efficient.
    • On a small screen, keep the device steady and use the selection text to confirm both tiles.

    Frequently asked questions

    Is progress saved?
    Yes. Cleared stages and best swap results are saved only in this browser.
    Does a wrong swap end the stage?
    No. You may keep arranging the board, or reset to the starting layout whenever you want.
    Does touching at a corner satisfy a neighbour clue?
    No. Habitats must share a full horizontal or vertical edge to count as touching.
    What changes in later chapters?
    Swap restrictions, diagonal movement, anchored habitats, and a four-swap budget are introduced across the six chapters.
