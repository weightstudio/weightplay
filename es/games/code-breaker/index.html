Descifra el código

Descifra el código es una campaña de deducción con cuatro casillas: usa pistas de posición y color para revelar un código oculto y avanza por 30 fases diseñadas.

JugabilidadDeducción de código de cuatro casillas
GéneroClásico · Puzzle · Estrategia
DificultadFácil de empezar, cada vez más exigente
Tiempo estimado2–8 minutos por fase

Mundo y misión

Cada fase presenta un código secreto de cuatro colores elegido de una paleta de seis. Al enviar un intento, el tablero separa dos pruebas: un color está en la posición exacta, o pertenece al código pero está en otra casilla. La diferencia convierte cada intento en información para el siguiente.

La campaña se divide en seis arcos de cinco fases. Escuela de señales evita los repetidos, Cámaras de eco los introduce, Paleta de sombras sella un color, Protocolo ancla fija una casilla, Bóveda de presión reduce los intentos y el Cifrado de corona combina las restricciones sin Pista.

Sistemas del juego

Construye un intento de cuatro colores y envíalo para leer la posición exacta y el color correcto. La fase decide el máximo de intentos, si puede haber repetidos, si un color está sellado y si una casilla comienza anclada.

Pista marca una casilla segura, pero tú eliges el color. Deshacer restaura el intento anterior para probar una hipótesis sin reiniciar la fase. La fase termina al acertar las cuatro posiciones o agotar los intentos.

Las fases superadas y la fase más alta desbloqueada se guardan localmente en este navegador. Resultado ofrece Fases, Siguiente fase y Repetir.

Cómo jugar

  1. Abre la campaña de 30 fases desde Inicio y elige una fase desbloqueada.
  2. Lee la regla del arco antes de adivinar: indica repetidos, color sellado, casilla anclada o límite de intentos.
  3. Envía un intento, separa las pistas de posición exacta y color correcto, y conserva solo deducciones que el tablero respalda.
  4. Usa Pista si te atascas y Deshacer para comparar una hipótesis; ninguna herramienta resuelve todo el código por ti.
  5. Completa la fase, revisa Resultado y elige Siguiente fase, Fases o Repetir para continuar.

Consejos

  • Sin repetidos, prueba colores variados y usa las posiciones exactas para fijar casillas en vez de cambiarlo todo.
  • Con repetidos, cuenta bien las pistas de color: un mismo color puede ocupar varias casillas.
  • Trata el color sellado como un límite y la casilla anclada como una prueba fija; resuelve alrededor de ambas restricciones.
  • Guarda Pista para una deducción realmente bloqueada y usa Deshacer para comparar sin gastar intentos a ciegas.

Progreso y dificultad

Las fases 1–5 enseñan posiciones exactas y colores cercanos sin repetidos. Después llegan repetidos, color sellado, casilla anclada, menos intentos y una combinación final de seis intentos sin Pista.

Cada arco contiene cinco fases que se desbloquean en orden. Repetir una fase superada sirve para reducir intentos y aprender la regla del arco; el progreso local mantiene abierto el siguiente paso.

Nota de diseño

Descifra el código mantiene el código oculto en cuatro casillas manejables y hace visibles las restricciones. La campaña de 30 fases amplía la decisión desde leer pruebas hasta controlar repetidos, colores no disponibles, información fija y recursos limitados. Teclado, ratón y táctil usan las mismas decisiones de casilla y color, y Resultado devuelve directamente a la campaña.

Información del jugador y guardado

Juega gratis en el navegador sin cuenta, compra, guardado en la nube, partida online ni flujo publicitario. El progreso, las fases superadas, el sonido y el mejor estado local quedan en este navegador; borrar sus datos puede eliminarlos.

Preguntas frecuentes

¿Qué significan las dos pistas?
Posición exacta significa que el color y la casilla coinciden. Color correcto significa que el color pertenece al código, pero está en otra casilla.
¿Se pueden repetir los colores?
Depende del arco. Lee la regla de la fase antes de descartar un color repetido.
¿Qué hace Pista?
Marca una casilla segura; tú eliges el color y envías la deducción.
¿Cómo aumenta la dificultad?
Se añaden repetidos, color sellado, casilla anclada, menos intentos y finalmente una fase sin Pista.
¿Se guarda el progreso?
Las fases superadas y la más alta desbloqueada se guardan solo en este navegador.
