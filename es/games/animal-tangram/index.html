Sistemas del juego

Toca la pieza o actívala con el teclado para girarla en pasos de 45°. Solo se fija cuando coinciden su centro y su ángulo con el contorno objetivo.

La pista coloca correctamente una pieza pendiente. Reiniciar restablece la figura actual; al completarla, se desbloquea el siguiente rompecabezas y puedes volver a jugar las figuras anteriores.

Cómo jugar

  1. Elige una figura de animal desbloqueada.
  2. Arrastra una pieza de color hasta el contorno que le corresponde.
  3. Tócala para girarla hasta que coincida.
  4. Coloca las siete piezas para completar el animal.

Si una pieza no encaja, su centro o su giro de 45 grados todavía no coincide. La pista coloca una sola pieza pendiente y Reiniciar vuelve a empezar únicamente la figura actual.

Consejos

  • Coloca primero los dos triángulos grandes.
  • Usa las esquinas y los bordes rectos para reconocer el cuadrado y el paralelogramo.
  • Si una pieza parece bien colocada pero no se fija, revisa el giro de 45°.

Progreso y dificultad

Treinta siluetas diseñadas comienzan con espacios amplios y poco a poco presentan superposiciones más estrechas, diseños reflejados y contornos de animales compactos. Puedes volver a jugar cada figura desbloqueada.

Nota de diseño

Las mismas siete piezas se usan para las figuras visibles, los objetivos, el encaje y los controles táctiles, con ratón o teclado. No hay temporizador ni diseño aleatorio, por lo que cada intento se puede resolver a partir de información espacial visible.

Nota para las familias

Este juego de puzles para niños no tiene anuncios ni requiere una cuenta. El progreso se guarda solo en este navegador. Es un pasatiempo de lógica espacial, no una evaluación formal de habilidades.

Preguntas frecuentes

¿Se debe utilizar cada pieza?
Sí. Cada forma utiliza las siete piezas clásicas de tangram.
¿Por qué no se fija una pieza?
Su centro o rotación aún no coincide con el objetivo.
¿Las pistas son limitadas?
No. La pista coloca correctamente una pieza sin resolver.
¿Puedo volver a jugar una figura?
Sí. Cada forma desbloqueada permanece disponible.
