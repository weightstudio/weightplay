세계와 사명

Rux는 한 번에 창고 하나씩 화물 방주를 복원하고 있습니다. 경로가 다시 열리려면 모든 룬 상자가 빛나는 부두에 도달해야 합니다.

시스템 작동 방식

한 번에 한 칸씩 이동하고 그 너머의 셀이 열려 있을 때만 상자를 밀어보세요. Magnetic Pull은 Rux가 남긴 공간으로 인접한 상자를 끌어당기는 동안 Rux를 뒤로 이동시킵니다.

이후 장에는 슬라이딩 아이스 레일, 신호 게이트, 연결된 화물 및 일방향 폭풍 벨트가 추가됩니다. 각 장치는 고정되고 판독 가능한 규칙을 따릅니다.

플레이 방법

  1. 무대 레일에서 잠금 해제된 창고를 선택하세요.
  2. 첫 번째 밀기 전에 전체 경로를 읽고 각 상자 뒤에 들어갈 수 있는 충분한 공간을 확보하십시오.
  3. 모든 룬 상자를 빛나는 부두와 연결하여 창고를 정리하세요.

전략 팁

  • 부두에서 뒤로 작업하고 최종 밀기 방향을 식별합니다.
  • 부두가 벽에 있지 않는 한 화물을 외벽으로 밀지 마십시오.
  • 일반적인 걷기나 밀기로는 회복할 수 없는 위치에 대해서는 자석으로 당기는 것을 아껴두십시오.

개발자 디자인 노트

모든 웨어하우스는 저작되고 해결 가능합니다. 실행 취소 및 다시 시작을 통해 플레이어는 클리어된 스테이지 진행 상황을 잃지 않고 경로를 테스트할 수 있습니다. The complete interface uses one centered logical layout with a 920-pixel maximum. Phone, landscape, and desktop views scale the same controls, hit areas, artwork, and game coordinates together instead of stretching individual pieces. Touch, mouse, and keyboard therefore act on the same legal state. The Main poster and Start Game action remain separate from Stage management, while Stage selection, Battle, dialogs, and Result keep their own bounded content and return path.

학부모 메모

You can play without creating an account. Progress is saved in local browser storage on the current browser profile, not in an online account or cross-device database. Clearing site data, using private browsing, changing browsers, or moving to another device can create a separate save or remove the existing one. Language, sound, and reduced-motion preferences follow the shared WeightPlay controls when the browser permits storage. No guide result is a medical, school, or professional assessment.

FAQ

얼마나 많은 창고가 포함되어 있나요?
6개의 규칙 장에 걸쳐 30개의 제작된 창고가 있습니다.
모든 단계를 해결할 수 있나요?
예. 모든 창고에는 검증된 솔루션이 있습니다.
풀은 무엇을 하나요?
당기기는 자기 충전 1개를 소비하고 Rux를 뒤로 이동시키며 인접한 상자를 Rux의 이전 셀로 끌어옵니다.
진행 상황이 저장되나요?
예. 지우기, 잠금 해제 및 최상의 결과는 이 브라우저에 로컬로 저장됩니다.
Which controls and screen sizes are supported?
The same rules support touch, mouse, and keyboard where the game uses those inputs. The interface scales as one logical layout across the required phone, landscape, and desktop viewports.
Can progress move automatically to another device?
No. This game currently saves to local browser storage only, so another browser profile or device begins with its own separate local progress unless a future account system is added.
