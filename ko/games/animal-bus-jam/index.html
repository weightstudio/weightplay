NIGHT TERMINAL CONTROL

판코의 버스 정리

Read the convoy order, route each queue, and keep the holding lane from locking up.

How to play

Only the first bus accepts passengers. A wrong color waits in the holding lane, in order. If that lane blocks before the active bus is filled, the terminal deadlocks.

  1. Check the active bus and its remaining seats.
  2. Dispatch only the front passenger of a queue.
  3. Use Undo before the holding lane becomes blocked.

World and Mission

30개의 야간 터미널이 가득 찬 상태로 운영됩니다. 현재 버스만 승객을 태울 수 있고, 다른 색은 배차된 순서대로 대기 통로에서 기다립니다.

모든 판단 정보가 보입니다. 전체 차량 행렬, 각 대기열, 현재 버스의 좌석, 사용 중인 대기 칸을 확인할 수 있습니다. 실패는 숨겨진 교통이나 타이머가 아니라 경로 선택에서 발생합니다.

How the Systems Work

각 대기열에서 움직일 수 있는 것은 맨 앞 승객뿐입니다. 색이 맞는 승객은 즉시 현재 버스에 탑승합니다.

색이 맞지 않는 승객은 대기 통로로 들어가며, 맨 앞 승객을 먼저 비워야 뒤의 승객이 탑승할 수 있습니다.

현재 버스가 차면 출발하고 다음 버스가 현재 목표가 됩니다. 대기 통로 맨 앞의 색이 맞으면 자동으로 탑승합니다.

대기 통로가 가득 차고 노출된 승객으로 현재 경로를 완성할 수 없으면 터미널이 막힙니다. 되돌리기는 정확한 이전 상태를 복원하고 다시 시작은 정류장을 초기화합니다.

How to Play

  1. 잠금 해제된 터미널을 선택하세요.
  2. 현재 버스와 남은 좌석, 차량 행렬의 다음 버스를 확인하세요.
  3. 미래 색을 대기 통로로 보내기 전에 모든 대기열의 맨 앞을 비교하세요.
  4. 대기 통로를 막지 않고 모든 버스를 채워 다음 터미널을 잠금 해제하세요.

Strategy Tips

  • 대기 칸을 무료 보관함이 아닌 한정 자원으로 취급하세요.
  • 미래 색을 보내기 전에 그 승객이 맨 앞의 방해물이 될지 확인하세요.
  • 대기 통로가 거의 차면 현재 색을 먼저 노출하세요.
  • 배차로 계획한 대기 순서가 바뀌면 바로 되돌리기를 사용하세요.

Campaign and Difficulty Growth

터미널 1에서 흐름을 배우고, 터미널 2부터는 잘못된 경로가 실제 막힘을 만들 수 있습니다.

후반에는 네 번째 노선, 긴 차량 행렬, 더 많은 대기열, 반복 색을 추가하고 고정된 세 대 구성이 아닌 두 칸 대기 통로를 사용합니다.

Developer Design Note

네 노선은 색과 문자 코드를 함께 사용합니다. 고정된 차량 행렬, FIFO 대기 통로, 결정적인 대기열, 검증된 해답이 휴대폰과 데스크톱 모두에서 읽기 쉬운 전략 퍼즐을 만듭니다. 전체 인터페이스는 중앙 정렬 단일 논리 레이아웃이며 최대 너비는 920픽셀입니다. 휴대폰, 가로 화면, 데스크톱은 같은 조작, 터치 영역, 아트, 게임 좌표를 함께 확대·축소하며 개별 요소를 늘이지 않습니다. 따라서 터치, 마우스, 키보드는 같은 합법 상태를 조작합니다. 메인 포스터와 시작 동작은 스테이지 관리와 분리되고, 스테이지 선택, 배틀, 대화창, 결과는 각자의 경계와 돌아가기 경로를 유지합니다.

학부모 메모

계정, 구매, 공개 순위표가 없는 일반 대상의 무시간 전략 퍼즐입니다. 클리어 기록은 이 브라우저에만 저장됩니다. 계정 없이 플레이할 수 있습니다. 진행은 현재 브라우저 프로필의 로컬 저장소에 저장되며 온라인 계정이나 기기 간 데이터베이스에는 저장되지 않습니다. 사이트 데이터를 지우거나, 시크릿 브라우징을 사용하거나, 브라우저 또는 기기를 바꾸면 별도 저장이 생기거나 기존 진행이 사라질 수 있습니다. 브라우저가 저장을 허용하면 언어, 사운드, 동작 줄이기 설정은 WeightPlay 공통 컨트롤을 따릅니다. 가이드 결과는 의료·학교·전문 평가가 아닙니다.

FAQ

대기열 중간의 승객을 보낼 수 있나요?
아니요. 노출된 각 대기열의 맨 앞만 움직일 수 있습니다.
왜 승객이 대기 통로로 갔나요?
현재 버스만 탑승시키고 다른 경로는 배차 순서대로 기다리기 때문입니다.
왜 터미널이 막혔나요?
대기 순서가 현재 경로를 막았고 노출된 승객으로 풀 수 없었기 때문입니다.
모든 터미널을 풀 수 있나요?
네. 기록된 30개의 해답 경로를 모두 자동으로 확인합니다.
어떤 조작과 화면 크기를 지원하나요?
게임이 사용하는 곳에서는 터치, 마우스, 키보드가 같은 규칙을 따릅니다. 지정된 휴대폰·가로·데스크톱 화면에서 하나의 논리 레이아웃으로 크기가 조정됩니다.
진행이 다른 기기로 자동 이동하나요?
아니요. 현재는 브라우저에만 저장되므로 다른 프로필이나 기기는 별도 진행을 가집니다.
