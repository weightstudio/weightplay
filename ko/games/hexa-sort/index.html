헥사 정렬

스택을 놓고 같은 윗면 색을 모아 연쇄 제거하세요.

플레이 방법

  1. 세 스택 중 하나를 고른 뒤 빈 육각형을 선택하세요.
  2. 맨 위 층을 옮기기 전에 인접 연쇄 전체를 계산합니다.
  3. 같은 색 10개가 모이면 사라지고 다음 층 연쇄가 시작됩니다.

제거·빈칸·같은 색 우선

전체 연쇄를 비교해 10개 제거, 비워지는 칸 수, 같은 색 집중도 순으로 선택합니다.

자주 묻는 질문

스테이지는 몇 개인가요?
직접 설계한 캠페인 스테이지 30개와 무한 모드가 있습니다.
놓은 뒤에 스택을 옮길 수 있나요?
아니요. 배치는 확정되며 같은 색의 맨 위 연속 묶음은 자동으로 처리됩니다.
어떤 칩을 옮길 수 있나요?
스택 맨 위에 연속으로 놓인 같은 색 칩만 인접한 스택으로 옮길 수 있습니다.
색상은 언제 제거되나요?
연결되어 처리된 스택이 같은 색 칩 10개에 도달하면 제거됩니다.
무한 모드는 무작위인가요?
제시되는 선택지는 달라지지만 규칙과 각 병합 결과는 현재 상태에 따라 결정됩니다.
진행 상황이 저장되나요?
캠페인 해금, 무한 모드 최고 점수와 설정은 현재 브라우저에 저장됩니다.
어떤 조작 방식과 화면 크기를 지원하나요?
게임이 지원하는 경우 터치, 마우스, 키보드를 사용할 수 있습니다. 화면은 휴대폰, 가로 화면, 데스크톱 크기에 맞춰 하나의 논리 레이아웃으로 조정됩니다.
진행 상황이 다른 기기로 자동 이동하나요?
아니요. 현재 브라우저 로컬 저장소에만 저장되므로 다른 브라우저 프로필이나 기기에는 별도의 진행 상황이 있습니다. 계정 기능이 추가되기 전까지 서로 공유되지 않습니다.
