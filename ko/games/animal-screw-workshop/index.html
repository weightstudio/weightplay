나사 워크숍 — 게임 가이드

황동 나사를 빈 구멍으로 옮겨 나무 동물 판을 모두 떨어뜨리세요. 서로 지지하는 판을 살피며 30개의 고정 퍼즐을 이동 제한 안에 해결합니다.

플레이 방법

나사를 선택한 뒤 빛나는 빈 구멍을 고르세요. 판을 받치는 구멍에서 나사가 모두 사라지면 판이 떨어집니다. 표시된 이동 수 안에 모든 판을 떨어뜨리지 못하면 실패합니다.

움직이기 전에 어떤 판들이 같은 나사를 공유하는지 확인하세요. 다음 나사를 옮길 수 있도록 실제 빈 구멍을 남겨 두세요. 겹친 층과 잠긴 나사도 살펴보세요. 여섯 장에서 기본 이동, 겹침, 공유 나사, 잠금, 빠듯한 경로, 혼합 배치를 익힙니다.

실행 취소는 직전 이동 전체를 되돌립니다. 힌트는 안전한 나사와 구멍을 표시하지만 대신 움직이지 않습니다. 다시 시작하면 퍼즐이 초기화됩니다. 완료한 퍼즐을 다시 풀어 별과 최소 이동 기록을 높일 수 있습니다.

나사 워크숍: 게임 가이드

터치, 마우스, 키보드를 지원합니다. 브라우저 저장소를 사용할 수 있으면 완료, 해제 진행, 최소 이동 수가 이 브라우저에 저장됩니다. 계정이나 클라우드 저장은 없습니다. 진행 중인 판은 새로고침 뒤 유지되지 않을 수 있습니다.

보호자 안내: 진단 목적이 아닌 논리 퍼즐로, 수순 계획과 지지 관계 파악, 계획 수정을 연습합니다. 카운트다운은 없어 자기 속도로 플레이할 수 있으며 퍼즐마다 이동 제한이 표시됩니다.

자주 묻는 질문

목표는 무엇인가요?
나사를 빈 구멍으로 옮겨 모든 나무 판의 지지대를 없애고 표시된 이동 제한 안에 해결하세요.
판은 왜 떨어지나요?
지지 구멍에 나사가 하나도 남지 않으면 바로 떨어집니다. 겹친 판 여러 개가 같은 나사를 공유할 수 있습니다.
힌트가 대신 움직여 주나요?
아니요. 안전한 나사와 목적 구멍만 표시합니다. 이동은 직접 선택하며 실행 취소로 마지막 이동을 되돌릴 수 있습니다.
이동 수를 다 쓰면 어떻게 되나요?
판이 남아 있으면 실패합니다. 다시 시작하고 빈 구멍을 어떻게 쓸지 먼저 계획하세요.
진행 상황은 어디에 저장되나요?
브라우저 저장소가 사용 가능하면 완료, 해제, 최소 이동 기록이 이 브라우저에 저장되며 계정과 동기화되지 않습니다.
