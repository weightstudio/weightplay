코드 브레이커

코드 브레이커는 네 칸 추리 캠페인입니다. 위치 일치와 색상 일치 힌트로 비밀 코드를 풀고 30개의 설계된 스테이지를 진행하세요.

게임플레이네 칸 코드 추리
장르클래식 · 퍼즐 · 전략
난이도쉽게 시작해 단계적으로 도전
예상 시간스테이지당 2–8분

세계와 목표

각 스테이지는 여섯 색 팔레트에서 만든 네 칸 비밀 코드를 제시합니다. 추측을 제출하면 색과 위치가 모두 맞는 정보와, 색은 코드에 있지만 위치가 다른 정보가 나뉘어 표시됩니다. 두 증거를 읽고 다음 추측을 좁혀 가세요.

캠페인은 다섯 스테이지씩 여섯 구간으로 나뉩니다. 중복 없는 신호 학교에서 시작해 중복 색, 봉인 색, 고정 슬롯, 줄어드는 추측 수를 거치고 마지막에는 힌트 없는 복합 조건을 만납니다.

게임 시스템

네 슬롯에 색을 넣어 추측을 제출합니다. 구간에 따라 최대 추측 수, 중복 허용 여부, 사용할 수 없는 색, 시작부터 고정된 슬롯이 달라집니다.

힌트는 안전한 다음 슬롯 하나를 표시하지만 색을 고르는 일은 직접 해야 합니다. 되돌리기는 직전 추측을 복원하므로 가설을 시험해도 스테이지를 처음부터 다시 시작할 필요가 없습니다. 네 칸을 모두 맞히거나 추측을 다 쓰면 스테이지가 끝납니다.

클리어한 스테이지와 가장 높은 해금 스테이지는 이 브라우저에 저장됩니다. 결과에서 스테이지 목록, 다음 스테이지, 다시 하기를 선택할 수 있습니다.

게임 방법

  1. 메인에서 30개 캠페인을 열고 해금된 스테이지를 고르세요.
  2. 추측하기 전에 구간 규칙을 읽고 중복 색, 봉인 색, 고정 슬롯, 추측 수를 확인하세요.
  3. 추측을 제출한 뒤 위치 일치와 색상 일치를 나누어 읽고 보드가 지지하는 결론만 남기세요.
  4. 막히면 힌트로 안전한 슬롯을 확인하고, 다른 가설을 비교할 때는 되돌리기를 사용하세요. 두 도구 모두 코드를 대신 풀지는 않습니다.
  5. 스테이지를 끝내고 결과를 확인한 뒤 다음 스테이지, 목록 또는 다시 하기로 이어 가세요.

전략 팁

  • 중복이 없는 구간에서는 색을 넓게 시험하고 위치 일치로 슬롯을 고정하세요. 매번 전체 추측을 바꿀 필요는 없습니다.
  • 중복이 허용되는 구간에서는 색상 일치 수를 세심하게 세세요. 같은 색이 여러 슬롯에 있을 수 있습니다.
  • 봉인 색은 추리의 경계로, 고정 슬롯은 확정 정보로 보고 나머지를 그 주변에 맞추세요.
  • 제한된 힌트는 정말 막힌 추리에 남겨 두고, 되돌리기로 가설을 비교해 추측을 아끼세요.

진행과 난이도

첫 다섯 스테이지는 중복 없이 위치와 색상 힌트를 읽는 법을 가르칩니다. 이후 중복 색, 봉인 색, 고정 슬롯, 적은 추측 수가 더해지고 마지막은 여섯 번 추측과 무힌트 조건입니다.

스테이지는 다섯 개 단위로 순서대로 해금됩니다. 클리어한 스테이지를 다시 하며 추측 수를 줄이고 각 구간 규칙을 익힐 수 있습니다.

개발자 디자인 노트

코드 브레이커는 비밀 코드를 네 슬롯으로 제한하고 모든 제약을 화면에 드러냅니다. 30개 스테이지는 증거 읽기에서 중복, 봉인 색, 고정 정보, 제한 자원 관리로 판단을 확장합니다. 키보드, 마우스, 터치는 같은 슬롯과 색 선택을 사용하며 결과에서 캠페인으로 돌아갈 수 있어 짧은 재도전이 쉽습니다.

플레이어 및 저장 정보

코드 브레이커는 브라우저에서 무료로 플레이할 수 있습니다. 계정, 구매, 클라우드 저장, 온라인 대전 또는 광고 흐름은 없습니다. 캠페인 진행, 클리어 상태, 사운드 설정과 로컬 최고 기록은 이 브라우저에 저장되며 사이트 데이터를 지우면 사라질 수 있습니다.

중복 색, 봉인 색, 고정 슬롯, 적은 추측 수, 마지막 무힌트 조건이 차례로 추가됩니다.
