프리즘 대대

포탑은 자동으로 발사합니다. 당신은 세 레인 중 지금 어디를 지킬지 결정하세요. 다가오는 적을 막을지, 폭탄을 제거할지, 공격력을 높일 코어를 모을지 선택해야 합니다.

세계와 목표

세 진입로가 동시에 공격받는 프리즘 요새를 30번의 방어로 지킵니다. 포대는 자동으로 발사하지만 선택한 차선만 집중 공격하므로 어떤 위협을 먼저 없앨지 결정해야 합니다.

다섯 번째 방어마다 챕터 보스가 등장합니다. 앞의 웨이브에서 규칙을 익히고 보스가 더 빽빽한 편대와 그 규칙을 결합합니다.

게임 시스템

차선을 누르거나 왼쪽·오른쪽 키, A/D로 선택한 포대를 움직이세요. 선택한 차선은 빛나며 현재 공격력으로 자동 공격합니다.

빛나는 에너지 코어를 쏘면 에너지가 쌓입니다. 코어가 아래에 도착할 때 같은 레인에 있으면 이번 전투의 공격력이 올라갑니다. 파란 보호막이 있는 코어는 보호막을 깨면 포탑 쪽으로 자동 이동합니다.

폭탄이 아래에 도착하면 남은 체력만큼 수정에 피해를 줍니다. 다른 레인으로 피한다고 막을 수는 없습니다. 다른 레인으로 통과한 적도 피해를 주며, 보스를 놓치면 패배할 수 있습니다.

방어로 얻은 조각은 연구실에서 연사 속도, 공격력, 코어 방어력을 올리지만 차선 판단을 대신하지는 않습니다.

충전이 100%이면 오버드라이브를 누르거나 스페이스를 누르세요. 3.6초 동안 더 빠르고 강하게 발사합니다. 위험한 레인에 집중하세요. 그동안 수정이 무적이 되지는 않습니다.

게임 방법

  1. 스테이지 레일에서 잠금 해제된 방어를 선택하세요.
  2. 세 차선을 읽고 가장 가깝거나 위험한 편대를 고르세요.
  3. 일반 피해보다 공격 코어 또는 폭탄 처리가 급할 때만 잠시 전환하세요.
  4. 모든 웨이브와 챕터 보스를 넘기고 크리스털 코어를 0으로 만들지 마세요.

전략 팁

  • 남은 체력만 보지 말고 거리와 특수 행동을 우선하세요.
  • 폭탄이 아래에 가까우면 코어보다 먼저 쏘세요. 제거하지 못해도 체력을 낮추면 피해가 줄어듭니다. 안전한 웨이브에서는 코어를 더 많이 쏘고 회수해 공격력 보너스를 늘리세요.

진행과 난이도

총 30개 미션이 5개씩 6개 장으로 나뉩니다. 2장부터 보호막 코어, 3·6장에는 이동 코어, 4장부터 폭탄, 5장부터 강력한 적이 등장합니다. 각 장 마지막은 보스전입니다. 수정 체력이 0이 되거나 시간이 끝나면 실패합니다.

개발자 디자인 노트

선택 차선, 적과의 거리, 특수 목표 상태, 코어 체력과 공격력이 함께 보입니다. 화면 크기가 달라도 전환은 포인터 대상이나 세 차선의 의미를 바꾸지 않습니다.

플레이어 및 저장 정보

계정, 구매, 공개 순위표가 필요하지 않습니다. 해금, 별, 조각과 연구실 강화는 이 브라우저에 저장됩니다.

자주 묻는 질문

포대가 자동으로 발사하나요?
네. 차선을 고르면 해당 포대가 자동으로 공격합니다.
공격 코어를 왜 모아야 하나요?

크리스털 코어를 해치는 것은 무엇인가요?
폭탄이 아래에 도착하면 남은 체력만큼 수정에 피해를 줍니다. 다른 레인으로 피한다고 막을 수는 없습니다. 다른 레인으로 통과한 적도 피해를 주며, 보스를 놓치면 패배할 수 있습니다.
방어는 몇 번 있나요?
6개 챕터에 총 30번 있으며, 다섯 번째 방어마다 보스가 나옵니다.
레인을 바꾸면 피해를 피할 수 있나요?
아니요. 폭탄은 어느 레인이든 남은 체력만큼 피해를 주고, 다른 레인을 통과한 적도 수정을 공격합니다. 오버드라이브는 화력 강화이지 무적이 아닙니다.
