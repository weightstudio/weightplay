프리즘 루트 가든

같은 색 수정 꽃을 연결하고 모든 칸을 채우세요.

플레이 방법

같은 색 프리즘을 교차 없이 잇고 색 관문을 지키며 모든 칸을 채우세요.

퍼즐전략경로 계획

게임 방법

  1. 수정 꽃에서 같은 색 꽃까지 드래그하세요.
  2. 상하좌우로만 이동합니다. 경로는 교차하거나 칸을 공유할 수 없습니다.
  3. 수정 문은 테두리와 같은 색 경로만 통과시킵니다.
  4. 모든 쌍을 연결하고 모든 칸을 채우면 다음 정원이 열립니다.

계획 팁

  1. 좁은 가장자리와 관문 통로를 먼저 확보하세요.
  2. 보드를 나누는 긴 경로부터 계획하세요.
  3. 되돌리기와 힌트는 진행도를 지우지 않습니다.

좁은 통로를 먼저 확보하세요. 실행 취소는 이전 보드를 복원하고 초기화는 경로를 지웁니다. 힌트는 미완성 경로 하나를 완성합니다. 진행은 이 브라우저에 저장됩니다.

상급 캠페인

30개 정원이 7×7에서 10×10으로 커지며 여섯 장에 색과 관문이 늘어납니다.

자주 묻는 질문

정원은 어떻게 완료하나요?
같은 색 꽃을 모두 연결하고 경로를 교차시키지 않은 채 열린 칸을 채우세요.
경로가 교차하거나 칸을 공유할 수 있나요?
아니요. 경로는 상하좌우로만 이어지고 각 칸은 하나의 경로만 사용할 수 있습니다.
프리즘 문은 어떻게 작동하나요?
테두리 색과 같은 경로만 문을 통과할 수 있습니다.
힌트는 무엇을 하나요?
힌트는 가능한 미완성 경로 하나를 완성하며 모든 경로를 대신 선택하지는 않습니다.
진행 상황이 저장되나요?
해제한 정원은 로컬 저장이 가능하면 이 브라우저에 저장됩니다. 사이트 데이터 삭제나 다른 브라우저 사용 시 유지되지 않을 수 있습니다.
