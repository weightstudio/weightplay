스도쿠

9×9 칸을 채워 각 행·열·3×3 구역에 1~9가 중복 없이 들어가게 하세요. 쉬움·보통·어려움 중 하나를 고르면 각 난이도에 정해진 수의 숫자가 처음부터 보입니다. 원하는 속도로 추리하세요.

세계와 목표

보드 전체가 숫자 퍼즐입니다. 처음 주어진 숫자가 행·열·3×3 구역마다 가능한 선택을 좁힙니다. 같은 규칙이 모든 칸에 적용되므로 한 숫자가 여러 구역의 후보를 동시에 줄일 수 있습니다.

쉬움·보통·어려움은 같은 완성 해답을 쓰고 시작 숫자의 배치만 다릅니다. 어려움은 보이는 숫자가 더 적어 다음 칸을 정하기 전에 더 많은 추론을 이어 가야 합니다.

게임 시스템

입력 가능한 칸을 선택하고 숫자 키패드로 1~9를 입력하세요. 주어진 칸은 잠겨 있으며 지우기로 직접 입력한 숫자를 없앨 수 있습니다.

선택한 칸의 행·열·3×3 구역에 같은 숫자가 이미 있으면 입력이 거부되고 충돌 안내가 나옵니다. 81칸을 채우고 이 구역들에 중복이 없어야 완료됩니다.

힌트는 다시 살펴볼 입력 가능한 칸 하나를 강조하지만 숫자를 대신 입력하지 않습니다. 실행 취소는 직전 입력을 복구하고 새 퍼즐은 선택한 난이도의 시작 보드를 초기화합니다.

카운트다운은 없습니다. 나가면 현재 입력과 실행 취소 기록이 버려집니다. 언어와 소리 설정은 이 브라우저에 저장되며 계정이나 구매는 필요하지 않습니다.

게임 방법

  1. 쉬움·보통·어려움 중 하나를 선택해 시작하세요.
  2. 빈칸을 고르고 해당 행·열·3×3 구역에 이미 있는 숫자를 확인하세요.
  3. 숫자 키패드로 후보를 입력하세요. 지우기나 실행 취소로 고칠 수 있고 힌트로 다시 살펴볼 칸을 표시할 수 있습니다.
  4. 81칸을 채우고 모든 행·열·구역에 숫자 중복이 없으면 퍼즐이 끝납니다.

전략 팁

  • 주어진 숫자가 많은 행·열·구역부터 보면 비교할 후보가 줄어듭니다.
  • 어떤 숫자가 3×3 구역의 한 칸에만 들어갈 수 있다면 넓은 패턴을 보기 전에 그곳에 두세요.
  • 입력 후 교차하는 행·열·구역을 다시 살펴보세요. 한 숫자가 세 범위의 선택지를 모두 좁힐 수 있습니다.
  • 힌트는 다시 살펴볼 칸만 표시합니다. 숫자 추리는 직접 해야 합니다.

진행과 난이도

단계 캠페인이 아니라 시작 단서 수가 다른 하나의 9×9 퍼즐입니다. 쉬움에 단서가 가장 많고 어려움에 가장 적습니다.

난이도가 달라도 보드 규칙은 같습니다. 더 많은 후보를 비교해야 합법적인 숫자를 찾을 수 있습니다. 타이머나 해금 진행은 없습니다.

개발자 디자인 노트

난이도마다 익숙한 9×9 보드 규칙은 그대로입니다. 행·열·구역 검사가 즉시 반응하고, 힌트는 답을 입력하지 않은 채 다시 살펴볼 칸만 짚어 줍니다.

플레이어 및 저장 정보

스도쿠는 일반 이용자를 위한 숫자 퍼즐입니다. 로그인이나 구매는 필요하지 않습니다. 현재 입력과 실행 취소 기록은 저장되지 않고 나가면 사라집니다. 언어와 소리 설정은 이 브라우저에 저장되며 사이트 데이터 삭제 시 함께 지워질 수 있습니다.
