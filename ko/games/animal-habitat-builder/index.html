서식지 빌더

여섯 보호구역에 물, 초원, 숲, 쉼터를 배치하세요. 배치 제한이 끝나기 전에 수량과 생태 규칙을 모두 만족해야 합니다.

게임 방식서식지 타일 전략
캠페인30스테이지 · 6개 규칙 장
핵심 순환배치 → 생태 확인 → 수정

게임 개요

서식지 빌더는 작은 보호구역을 하나의 시스템으로 설계하는 배치 퍼즐입니다. 각 보호구역은 4×5 칸과 물, 초원, 숲, 쉼터 타일을 사용합니다. 목표 패널이 필요한 수량을 보여 주고, 뒤 스테이지는 이웃 칸과 보드 가장자리의 관계를 추가합니다.

보호구역 규칙

타일을 고른 뒤 빈 칸을 클릭하거나 터치하세요. 배치와 교체는 이동을 사용하며 X 칸에는 지을 수 없습니다. 필요한 수량과 모든 생태 검사가 통과되어야 완료됩니다. 스테이지에 따라 물이나 숲 연결, 양쪽 가장자리 물, 가장자리 숲, 숲 옆 쉼터, 물 옆 초원이 필요합니다.

결과 화면에서 성공 또는 제한 초과를 확인합니다. 리셋으로 현재 보호구역을 다시 만들고, 완료한 스테이지는 목록에서 다시 플레이할 수 있습니다.

진행과 난도

1~2는 수량과 연결된 물을 가르치고, 3은 가장자리 숲과 숲 옆 쉼터, 4는 물 옆 초원을 추가합니다. 5는 X 칸과 양쪽을 잇는 물, 연결 숲을 넣고 6은 조건을 결합합니다. 7~30은 여섯 장의 규칙을 바꾸어 조합하며 30은 피날레입니다.

전략 팁

첫 타일 전에 검사 아이콘을 읽으세요. 가장자리가 필요한 조건의 길을 남기고, 어려운 인접 조건부터 배치하면 X 칸에 막히지 않습니다. 수량과 생태 관계를 따로 확인하고 물이나 숲의 연결 여부를 끝까지 보세요.

플레이어와 저장

터치, 마우스, 포인터는 같은 배치 규칙을 사용합니다. 계정이나 구매가 필요 없습니다. 완료 스테이지와 로컬 최고 기록은 이 브라우저에만 저장되며 사이트 데이터를 지우면 사라질 수 있습니다.

자주 묻는 질문

보호구역을 어떻게 완료하나요?
제한 안에 필요한 타일 수량과 모든 생태 검사를 통과하세요.
X 칸에 놓을 수 있나요?
아니요. X 칸은 스테이지의 고정 장애물입니다.
후반 스테이지에서 무엇이 바뀌나요?
연결, 가장자리, 쉼터, 초원, 양쪽 물, X 칸 조건이 조합됩니다.
스테이지는 몇 개인가요?
여섯 규칙 장에 30스테이지가 있고 30이 피날레입니다.
진행 상황이 저장되나요?
완료 스테이지와 로컬 최고 기록은 이 브라우저에만 저장됩니다.

관련 게임

관찰이나 타이밍을 중심으로 한 다른 동물 퍼즐도 해 보세요.
