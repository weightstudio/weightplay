세계와 사명

Panko는 30개의 그늘진 정원을 다시 열었습니다. 오프닝 정원에서는 뚜렷한 경로 모양을 가르치고, Garden 6에서는 두 개의 동시 태양을 소개하며, 마지막 장은 조밀한 이중 소스 네트워크를 결합합니다.

모든 애니메이션 빔은 현재 보드를 따르므로 경로가 회전하고, 순환하고, 정원을 떠나거나 공유 연꽃에 도달하는 위치를 정확하게 보여줍니다.

시스템 작동 방식

거울을 탭하여 두 개의 대각선 반사 상태 사이에서 회전합니다.

각 광선은 한 번에 한 셀씩 전진하고 실제로 도달한 거울에서만 반사되며 가장자리나 반복되는 루프에서 멈춥니다.

이중 소스 스테이지는 독립적으로 추적된 두 광선이 연꽃 세포에 들어갈 때만 지워집니다. 가까운 노선이나 완성된 경로는 포함되지 않습니다.

힌트는 작성된 솔루션과 다른 하나의 경로 미러를 수정하고 손대지 않은 미끼를 무시합니다. 재설정은 모든 시작 회전을 복원합니다.

플레이 방법

  1. 잠금 해제된 정원을 선택하세요.
  2. 연꽃에서 뒤로 추적하고 눈에 보이는 모든 태양에서 앞으로 추적합니다.
  3. 하나의 거울을 회전시킨 다음 업데이트된 모든 빔 경로를 읽습니다.
  4. 반사된 모든 최종 세그먼트를 연꽃에 연결하고 결과부터 계속합니다.

전략 팁

  • 이미 빔에 닿은 거울부터 시작하십시오.
  • 불가능한 반사 선택을 제거하려면 가장자리 종료를 사용하십시오.
  • 루프가 나타나면 빛을 이전 셀로 다시 보내는 첫 번째 거울을 변경하십시오.
  • 경로가 사용할 수 있을 만큼 가까워질 때까지 손대지 않은 거울을 회전하지 마십시오.

캠페인 및 난이도 성장

정원 1-10은 10개의 서로 다른 경로 토폴로지를 사용하며 필요한 회전 수는 2개에서 6개로 늘어납니다. Garden 6에는 이중 소스 완성 규칙이 도입되었습니다.

Gardens 11-20은 다중 소스 네트워크와 미끼를 다양하게 제공합니다. Gardens 21-30은 검증된 최단 솔루션에 10개 또는 11개의 회전이 필요한 조밀한 이중 소스 경로를 사용합니다.

개발자 디자인 노트

빔, 거울 중심, 그리드 셀 및 해결 상태 추적은 하나의 좌표계를 공유하므로 시각적 경로와 규칙이 서로 다른 화면 크기에서 분리될 수 없습니다. 전체 인터페이스는 최대 920픽셀의 중앙 집중식 논리적 레이아웃을 사용합니다. 휴대폰, 가로 및 데스크탑 보기는 개별 부분을 늘리는 대신 동일한 컨트롤, 히트 영역, 아트워크 및 게임 좌표를 함께 확장합니다. 따라서 터치, 마우스 및 키보드는 동일한 법적 상태에서 작동합니다. 메인 포스터와 게임 시작 작업은 스테이지 관리와 별도로 유지되는 반면, 스테이지 선택, 전투, 대화 및 결과는 자체적으로 제한된 콘텐츠와 반환 경로를 유지합니다.

학부모 메모

타이머, 계정, 구매, 공개 순위가 없습니다. 정리된 정원과 지역 이동 기록이 이 브라우저에 유지됩니다. 계정을 만들지 않고도 플레이할 수 있습니다. 진행 상황은 온라인 계정이나 교차 장치 데이터베이스가 아닌 현재 브라우저 프로필의 로컬 브라우저 저장소에 저장됩니다. 사이트 데이터 삭제, 시크릿 브라우징 사용, 브라우저 변경, 다른 기기로 이동 시 별도의 저장을 생성하거나 기존 저장을 제거할 수 있습니다. 브라우저가 저장을 허용하는 경우 언어, 소리 및 모션 감소 기본 설정은 공유된 WeightPlay 컨트롤을 따릅니다. 가이드 결과는 의학적, 학교 또는 전문적 평가가 아닙니다.

FAQ

연꽃은 왜 깨어나지 않았나요?
모든 활성 빔은 정확한 셀에 들어가야 합니다. 이중 소스 정원에서는 완성된 빔 하나만으로는 충분하지 않습니다.
빛이 거울을 통과할 수 있나요?
아니요. 도달한 미러는 항상 현재 상태에 따라 반영됩니다.
빔 루프가 가능합니까?
예; 해당 경로를 반복하는 첫 번째 거울을 회전합니다.
힌트가 보드를 완성하나요?
아니요, 유용한 경로 미러 하나를 수정합니다.
어떤 컨트롤과 화면 크기가 지원되나요?
동일한 규칙은 게임에서 해당 입력을 사용하는 터치, 마우스 및 키보드를 지원합니다. 인터페이스는 필요한 휴대폰, 가로 및 데스크톱 뷰포트에 걸쳐 하나의 논리적 레이아웃으로 확장됩니다.
진행 상황이 자동으로 다른 장치로 이동할 수 있나요?
아니요. 이 게임은 현재 로컬 브라우저 저장소에만 저장되므로 향후 계정 시스템이 추가되지 않는 한 다른 브라우저 프로필이나 장치는 별도의 로컬 진행 상황으로 시작됩니다.
