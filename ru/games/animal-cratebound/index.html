Мир и миссия

Рукс восстанавливает грузовой ковчег по одному складу за раз. Каждый ящик с рунами должен достичь светящегося причала, прежде чем маршрут снова откроется.

Как работают системы

Перемещайте по одному квадрату за раз и толкайте ящики только тогда, когда ячейка за ними открыта. Магнитное притяжение перемещает Рукса назад, втягивая соседний ящик в пространство слева от Рукса.

В последующих главах добавляются раздвижные ледяные рельсы, сигнальные ворота, связанный груз и односторонние штормовые пояса. Каждое устройство следует фиксированному и читаемому правилу.

Как играть

  1. Выберите разблокированный склад на перилах сцены.
  2. Прочтите весь маршрут перед первым толчком и оставьте достаточно места, чтобы пройти за каждым ящиком.
  3. Сопоставьте каждый ящик с рунами со светящимся доком, чтобы очистить склад.

Советы по стратегии

  • Двигайтесь назад от доков и определите окончательное направление толчка.
  • Не прижимайте груз к внешней стене, если его док-станция не находится на этой стене.
  • Сохраните магнитное притяжение для положений, которые нельзя восстановить обычной ходьбой и толканием.

Кампания и рост сложности

Тридцать складов охватывают шесть глав: «Первый грузовой», «Полярные рельсы», «Сигнальная палуба», «Магнитный отсек», «Двойной груз» и «Штормовой ковчег».

Примечание разработчика к проекту

Каждый склад авторский и решаемый. Отмена и перезапуск позволяют игрокам протестировать маршрут, не теряя прогресс пройденного этапа. The complete interface uses one centered logical layout with a 920-pixel maximum. Phone, landscape, and desktop views scale the same controls, hit areas, artwork, and game coordinates together instead of stretching individual pieces. Touch, mouse, and keyboard therefore act on the same legal state. The Main poster and Start Game action remain separate from Stage management, while Stage selection, Battle, dialogs, and Result keep their own bounded content and return path.

Примечание для родителей

You can play without creating an account. Progress is saved in local browser storage on the current browser profile, not in an online account or cross-device database. Clearing site data, using private browsing, changing browsers, or moving to another device can create a separate save or remove the existing one. Language, sound, and reduced-motion preferences follow the shared WeightPlay controls when the browser permits storage. No guide result is a medical, school, or professional assessment.

Часто задаваемые вопросы

Сколько складов включено?
В шести главах правил имеется 30 авторских складов.
Можно ли решить каждый этап?
Да. На каждом складе есть проверенное решение.
Что делает Пулл?
Притяжение тратит один магнитный заряд, перемещает Рукса назад и втягивает соседний ящик в предыдущую ячейку Ракса.
Прогресс сохраняется?
Да. Очистки, разблокировки и лучшие результаты сохраняются локально в этом браузере.
Which controls and screen sizes are supported?
The same rules support touch, mouse, and keyboard where the game uses those inputs. The interface scales as one logical layout across the required phone, landscape, and desktop viewports.
Can progress move automatically to another device?
No. This game currently saves to local browser storage only, so another browser profile or device begins with its own separate local progress unless a future account system is added.
