世界与任务

一条小型救援路线被蓝色冰墙封住。收集每颗浆果，只改变真正需要的障碍，并在漂行者封住缺口前继续前进。

游戏系统

使用方向键、WASD 或画面上的方向控制，每次移动一个格子。按空格键破坏前方冰墙，按 F 建造短冰墙。

敌人会在你反复移动后前进。收集所有浆果就能清除房间；碰撞会阻断路线，并送你进入专注重试。

21–30: 每次成功改冰，漂行者就会移动。 26–30: 收完浆果后，返回起点格。

玩法说明

  1. 选择章节，读取浆果数量和路线提示。
  2. 一次移动一格；当蓝色冰墙封住下一条有用路线时，使用破冰。
  3. 需要拖延敌人时，使用建造冰墙建立短暂屏障。
  4. 收集所有浆果，再在结果画面选择下一房间、重试或返回章节。

策略提示

  • 破冰前先规划接下来两格，确认开口真的会形成路线。
  • 收集露出的浆果时，让敌人留在屏障另一侧。
  • 如果路线封闭，快速重试并改变破冰顺序，不要重复同一路径。

关卡与难度成长

六个章节、30 个房间从第一次解冻逐步走向分岔路线、漂行者压力与最终融冰；路线通过可破坏和可建造的冰墙变化，而不是靠隐藏规则。

21–25: 回音冰原. 26–30: 归途救援. 通关得★，每达成一项目标再得★。 改冰 ≤ 2; 步数 ≤ 46–62.

开发设计理念

冰原迷宫救援是原创网格救援益智游戏，结合直接的冰墙编辑、确定性的短房间、可见的敌人压力，以及适用于触控和桌面的响应式控制。
