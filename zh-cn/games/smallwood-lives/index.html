林间一生

《林间一生》是可用滑鼠、触控或键盘游玩的回合制人生故事游戏。世界会等待你的决定，没有倒数计时。三十章依序探索友谊、承诺、搬家、教导学徒与留下传承。

怎么写下你的林间人生

  1. 选择已开启的章节。每段人生都有自己的动物、朋友、起始资源与日常机会。
  2. 每季最多两次行动。先查看资源变化再确认：休息恢复精神，探索取得材料与自然知识，手作累积能力。
  3. 第二、六、十季会遇到人生事件，稍后的回响只记录真实选择。承诺需要在期限前花一次行动履行。
  4. 走完十二季，把人生收进相册。即使未达成选做的心愿，也会开启下一章。

日常行动

友谊、手作与自然最高三点，精神最高六点，材料最高九份。费用与能力要求会在确认前显示。搬家会改变远近关系；承诺最多延后两季一次，且新期限不能超过这一生。

收藏

每章都有永久纪念物与心愿版本。每页相册可保留三段人生，替换一段仍保留已发现的分支。每完成五章，免费开启一间五格展室。钻石只购买永久场景装饰，不增加能力、行动或寿命。

章节

  2. 河湾 — 与 B 的友谊达二，同时保留与 A 的一点友谊。
  3. 山坡市集 — 以两点以上的能力教会学徒。
  4. 海风林 — 手作达二，建好工坊。
  5. 雪松谷 — 搭建遮棚，并保留至少两份材料。
  6. 星灯广场 — 选一位听众、教会对方，并留下回忆。

游玩方法

会因为运气不好而失败吗？
没有死亡抽选或财富排名，走完十二季就算完成。没有实现心愿，是另一种故事，不是失败的人生。
可以接著上次继续吗？
每次选择都先储存在这个浏览器，再改变画面。续玩会回到原本的选择；清除浏览器资料会移除进度，另一个标签页更新时则需要重载。
重玩会改变起点吗？
「相同的起点」会使用原本的种子；重新点选已完成章节则开始新人生。种子固定起点与日常机会，但不决定你的选择。
和《80亿分之1》有什么关系？
创作灵感来自《80亿分之1》对不同人生起点与选择的探索。《林间一生》是 WeightPlay 独立制作的原创游戏，与原作无隶属、合作或授权关系。
