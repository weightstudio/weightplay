方块爆破

Block Blast 是一款原创的 8 x 8 空间谜题，包含 30 个编写的地形任务和无尽的高分模式。放置当前组中的每个固定形状，清除完整的行或列，并为仍在托盘中等待的形状保留足够的开放空间。

难度容易挑战
预估游玩时间2-10分钟
练习能力规划 · 空间推理 · 焦点

世界与任务

该战役由三十个紧凑的谜题任务组成，而不是一张空板的三十个副本。泥土、冰、石头、宝石、锁、颜色目标和设定限制组合成不同的规划问题。

无尽模式会移除任务目标并继续处理三形状套装。其平衡的形状池包括小型连接器、中等角、长的五单元件、较大的矩形，以及偶尔的 3 x 3 正方形，因此粗心的板最终会耗尽合法空间。

游戏系统

形状保持托盘中显示的方向，放置后无法移动。选择一个形状并点击合法板单元，或将其拖动到凸起的着陆预览上。

整行或整列会立即清除。只有清除线路才奖励积分；单独放置方块不会增加分数。

使用所有三种形状可以得到一个新的固定集。战役任务还可以要求路线、地形、宝石、颜色或有限设定的目标。一旦未使用的托盘形状都不符合合法配合，则运行结束。

冰块在放置的方块下方仍然可见，直到该线清除为止，而石头和锁会阻挡放置。宝石细胞在被覆盖时会打开相连的锁。

玩法说明

  1. 选择“战役”进行三十个任务，或选择“无尽”进行一次连续的得分运行。
  2. 选择板下方的三个形状之一。
  3. 点击打开的单元格或将形状拖动到合适的位置。
  4. 完成一行或一列即可清除并得分。
  5. 使用所有三个形状接收下一组，同时为每个剩余形状留出空间。

策略提示

  • 在进行第一次放置之前检查所有三个形状。
  • 保留几个开放区域，而不是完美填充一个角落。
  • 当下一个形状确保安全时，构建相交的行和列清除。
  • 不要计划只接收小件；长形状和偶尔的 3 x 3 正方形是无尽模式的一部分。
  • 在地形任务中，区分必须清除的单元和永远无法被占领的石单元。

关卡与难度成长

第 1-5 阶段介绍生产线目标和干净的董事会规划。

后面的章节会分层泥土、冰、石头、宝石、锁、颜色目标、混合目标和更严格的设定限制。

玩家选择创建的棋盘状态会带来无尽的难度，而形状分布则保证了常规的大块压力，而不仅仅是处理硬形状。

开发设计理念

分数和效果与实际的清线相关。清除光束保持在已完成的行或列​​的中心，碎片从清除的单元格中落下，并且当玩家立即选择下一个托盘块时，白色得分增益会出现在清除的区域上，而不会重播。 完整的界面使用一个居中的逻辑布局，最大像素为 920。手机、风景和桌面视图将相同的控件、点击区域、艺术作品和游戏坐标一起缩放，而不是拉伸各个部分。因此，触摸、鼠标和键盘作用于相同的合法状态。主海报和开始游戏操作与舞台管理保持分离，而舞台选择、战斗、对话和结果保留自己的有限内容和返回路径。

Block Blast 是一款适合普通观众的浏览器益智游戏，建议 9 岁以上儿童和家庭游戏。无需帐户。活动解锁和首选项仅存储在此浏览器中，因此清除站点数据或更改设备可能会删除本地进度。 您无需创建帐户即可玩。进度保存在当前浏览器配置文件的本地浏览器存储中，而不是在线帐户或跨设备数据库中。清除站点数据、使用隐私浏览、更改浏览器或移动到另一台设备可以创建单独的保存或删除现有的保存。当浏览器允许存储时，语言、声音和简化动作首选项遵循共享的 WeightPlay 控制。没有任何指导结果是医学、学校或专业评估。

常见问题

形状可以旋转吗？
不会。每个托盘形状都会保持其显示方向。
积分什么时候增加？
只有完成的行或列​​才奖励积分；简单地放置一个形状不会。
包括几个阶段？
有 30 个编写的战役任务以及无限的无尽运行。
冰和石头有什么作用？
冰块在放置的方块下方仍然可见，直到其线条消失为止；石头不能被占用。
为什么跑步结束了？
当当前托盘中没有未使用的形状具有合法位置时，运行结束。
进度保存了吗？
活动解锁和偏好设置本地存储在此浏览器中。
支持哪些控件和屏幕尺寸？
相同的规则支持游戏使用这些输入的触摸、鼠标和键盘。该界面可扩展为跨所需的手机、横向和桌面视口的一种逻辑布局。
进度可以自动转移到另一台设备吗？
不会。该游戏目前仅保存到本地浏览器存储，因此另一个浏览器配置文件或设备会以其自己单独的本地进度开始，除非添加未来的帐户系统。
