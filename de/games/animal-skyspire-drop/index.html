Geschichte und Aufgabe

Fia reist in einer Kometenkugel durch eine Kette instabiler Himmelstürme. Jeder geräumte Turm stellt einen Abschnitt der Höhenroute wieder her und rückt das Rettungstor näher.

Spielregeln

Ziehen Sie über den Turm oder verwenden Sie Links und Rechts, um jeden Ring gemeinsam zu drehen. Eine türkisfarbene Plattform ist sicher; Ein violetter verfluchter Sektor beendet den Lauf, es sei denn, ein Schild oder ein aufgeladener Comet Break schützt Fia.

Aufeinanderfolgende Lückenabstiege laden Comet Break ein. Himmelssplitter und Sterne von geräumten Türmen werden lokal gespeichert und können die Kontrolle, Schilde und andere optionale Comet Forge-Upgrades verbessern.

So wird gespielt

  1. Wählen Sie einen freigeschalteten Skyspire aus der horizontalen Turmschiene.
  2. Drehen Sie den Ring so, dass vor der nächsten Landung eine Öffnung oder eine sichere türkisfarbene Plattform Fia erreicht.
  3. Führen Sie eine Reihe sauberer Abstiege durch, um Comet Break aufzuladen, und fahren Sie dann weiter zum Rettungstor.

Tipps

  • Verwenden Sie einen kurzen, sicheren Sprung, wenn Sie Zeit brauchen, um den nächsten Ring zu erkennen, anstatt jeden Sturz zu erzwingen.
  • Eine lange Gap-Kette baut schnell Kraft auf, aber die nächste Landung kommt schneller; Planen Sie die folgende Eröffnung, bevor Sie sich verpflichten.
  • Bewahren Sie einen Schild oder einen aufgeladenen Comet Break für ein überfülltes verfluchtes Segment auf, anstatt ihn für einen einfachen Ring zu verwenden.

Fortschritt und Schwierigkeit

Dreißig verfasste Skyspires erstrecken sich über sechs Kapitel. Spätere Türme fügen zerbrechliches Glas, schwebende Ringe, umgekehrte Kontrollen, Ladekristalle, Schildtore und Crownfall-Layouts hinzu, die frühere Regeln kombinieren.

Hinweis zur Gestaltung

Every tower keeps the same direct rotation control while changing ring timing and hazards, so challenge comes from reading the next landing rather than learning a new input scheme. The complete interface uses one centered logical layout with a 920-pixel maximum. Phone, landscape, and desktop views scale the same controls, hit areas, artwork, and game coordinates together instead of stretching individual pieces. Touch, mouse, and keyboard therefore act on the same legal state. The Main poster and Start Game action remain separate from Stage management, while Stage selection, Battle, dialogs, and Result keep their own bounded content and return path.

Häufige Fragen

Wie viele Himmelstürme gibt es?
Es gibt 30 verfasste Skyspires in sechs Kapiteln.
Was kostet Comet Break?
Das Passieren aufeinanderfolgender Öffnungen baut die Ladung auf. Eine volle Ladung kann eine Gefahr durchbrechen.
Speichert Fortschritt?
Ja. Gelöschte Türme, Sterne, Bestzeiten, Himmelssplitter und Comet Forge-Upgrades werden lokal gespeichert.
Welche Steuerelemente und Bildschirmgrößen werden unterstützt?
Die gleichen Regeln unterstützen Berührung, Maus und Tastatur, wenn das Spiel diese Eingaben verwendet. Die Benutzeroberfläche lässt sich als ein logisches Layout über die erforderlichen Telefon-, Querformat- und Desktop-Ansichtsfenster hinweg skalieren.
Kann der Fortschritt automatisch auf ein anderes Gerät verschoben werden?
Nein. Dieses Spiel wird derzeit nur im lokalen Browserspeicher gespeichert, sodass ein anderes Browserprofil oder Gerät mit einem eigenen separaten lokalen Fortschritt beginnt, sofern kein zukünftiges Kontosystem hinzugefügt wird.
