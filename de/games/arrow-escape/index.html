Pfeilflucht

Arrow Escape ist ein 30-stufiges Ordnungsrätsel. Lesen Sie den vollständigen Weg vor jedem Pfeil, entfernen Sie einen Block nur, wenn dieser Weg frei ist, und decken Sie eine sichere Sequenz durch Wände, rotierende Pfeile, passende Schlösser, Eis, Portale und Einbahntore auf.

SchwierigkeitLeicht bis anspruchsvoll
Geschätzte Spielzeit2-8 Minuten
FähigkeitenPlanung · Räumliches Denken · Konzentrieren Sie sich

Geschichte und Aufgabe

Jede Stufe ist ein deterministisches Fluchtbrett und kein zufälliges Layout. Die gleiche Phase beginnt immer mit den gleichen Blöcken und hat immer eine verifizierte Gesamtlösung.

In sechs Lehrkapiteln wird jeweils eine Regel vorgestellt, bevor in den letzten fünf Rätseln alle Mechaniken kombiniert werden.

Spielregeln

Ein normaler Pfeil kann nur dann weggehen, wenn jede Zelle auf seinem Strahl frei ist. Eine blockierte Wahl rüttelt und identifiziert das erste Hindernis, ohne einen Zug aufzuwenden.

Rotierende Pfeile drehen sich einmal, bevor sie entkommen können. Schlüssel öffnen nur die passenden Schlösser, und wenn ein benachbarter Block entfernt wird, taut das Eis auf.

Portale setzen denselben Strahl von ihrem gepaarten Ausgang aus fort. Ein Einwegtor akzeptiert nur die entsprechende Richtung.

Hinweis markiert einen sicheren nächsten Pfeil und verschiebt den Tastaturfokus darauf, spielt den Zug jedoch nie für Sie ab oder wechselt das Spielbrett.

So wird gespielt

  1. Wählen Sie eine entsperrte Bühne aus der horizontalen Bühnenschiene.
  2. Überprüfen Sie die Richtung und die vollständige Route jedes Pfeils.
  3. Tippen, klicken oder fokussieren und aktivieren Sie einen Pfeil, dessen Route klar ist.
  4. Verwenden Sie den Blocker-Umriss, um eine unsichere Entscheidung zu verstehen, oder verwenden Sie den Hinweis für einen beratenden Schritt.
  5. Entferne jeden Pfeil, um die Bühne zu verlassen und das nächste Rätsel freizuschalten.

Tipps

  • Beginnen Sie mit Pfeilen, die bereits auf eine offene Kante zeigen.
  • Verfolgen Sie vor dem Festschreiben den gesamten Strahl, einschließlich des Raums nach einem Portal.
  • Wenn ein Schlüssel oder ein eingefrorener Block erscheint, planen Sie, welche Änderungen sich durch seine Entfernung für Pfeile in der Nähe ergeben.
  • Ein geblockter Versuch kostet keinen Zug, also verwenden Sie den hervorgehobenen ersten Blocker als Information, anstatt wiederholt zu raten.

Fortschritt und Schwierigkeit

In den Stufen 1–5 werden klare Strahlen und Entfernungsreihenfolge vermittelt.

In den Stufen 6–15 werden ineinandergreifende Reihen und feste Wände hinzugefügt.

In den Stufen 16–25 werden Rotation, passende Schlösser, Schlüssel und Eis eingeführt.

Die Etappen 26–30 kombinieren Portale und Einwegtore mit den früheren Regeln.

Hinweis zur Gestaltung

Eindeutige legale Pfeile reagieren sofort, sodass schnelle Spieler aufeinanderfolgende sichere Bewegungen ausführen können, ohne auf eine frühere Fluganimation warten zu müssen. Der Platinenstatus wird weiterhin deterministisch aufgelöst und doppelte Berührungen eines bereits entfernten Pfeils werden ignoriert. The complete interface uses one centered logical layout with a 920-pixel maximum. Phone, landscape, and desktop views scale the same controls, hit areas, artwork, and game coordinates together instead of stretching individual pieces. Touch, mouse, and keyboard therefore act on the same legal state. The Main poster and Start Game action remain separate from Stage management, while Stage selection, Battle, dialogs, and Result keep their own bounded content and return path.

Häufige Fragen

Wie viele Etappen sind enthalten?
Es gibt 30 handgefertigte Level in sechs Regelkapiteln, und Level 30 bleibt wiederholbar.
Benutzt ein blockierter Tap einen Zug?
Nein. Es identifiziert den ersten Blocker und lässt das Board unverändert.
Löst Hint das Rätsel automatisch?
Nein. Hinweis markiert und fokussiert einen sicheren nächsten Pfeil, aber Sie entscheiden immer noch, ob Sie ihn spielen möchten.
Können sich mehrere Pfeile gleichzeitig bewegen?
Ja. Bestimmte legale Pfeile können ihre Fluchtanimationen sofort beginnen, ohne dass eine globale Abklingzeit für die Eingabe erforderlich ist.
Wie funktionieren Portale?
Ein Pfeil dringt in ein Portal ein und setzt sich in derselben Richtung unmittelbar hinter dem gepaarten Ausgang fort.
Wird der Fortschritt gespeichert?
Stufenfreischaltungen und Einstellungen werden lokal in diesem Browser gespeichert.
Which controls and screen sizes are supported?
The same rules support touch, mouse, and keyboard where the game uses those inputs. The interface scales as one logical layout across the required phone, landscape, and desktop viewports.
Can progress move automatically to another device?
No. This game currently saves to local browser storage only, so another browser profile or device begins with its own separate local progress unless a future account system is added.
