FarbsortierungHex-StapelKettenplanung

Spielanleitung

  1. Wähle einen von drei Stapeln und dann ein leeres Sechseck.
  2. Die ganze Nachbarkette wird berechnet, bevor eine Deckschicht wandert.
  3. Zehn gleiche Chips verschwinden und zeigen die nächste Kette.

Die ganze Kette wird verglichen: zuerst zehn löschen, dann weniger Felder belegen, zuletzt gleiche Farben bündeln.

Häufige Fragen

Wie viele Stufen gibt es?
Die Kampagne umfasst 30 handgefertigte Stufen sowie einen Endlosmodus.
Kann ich einen Stapel nach dem Ablegen bewegen?
Nein. Das Ablegen ist endgültig; gleiche Farbfolgen oben werden automatisch aufgelöst.
Welche Chips kann ich bewegen?
Nur eine zusammenhängende Folge derselben Farbe oben auf einem Stapel kann auf einen benachbarten Stapel bewegt werden.
Wann wird eine Farbe entfernt?
Ein verbundener, aufgelöster Stapel wird entfernt, sobald er zehn gleichfarbige Chips enthält.
Ist der Endlosmodus zufällig?
Die Angebote wechseln, aber Regeln und jede Kombinationsentscheidung ergeben sich eindeutig aus dem aktuellen Zustand.
Wird der Fortschritt gespeichert?
Kampagnenfreischaltungen, der Endlosrekord und Einstellungen werden lokal in diesem Browser gespeichert.
Welche Steuerungen und Bildschirmgrößen werden unterstützt?
Sofern das Spiel sie unterstützt, funktionieren Touch, Maus und Tastatur. Die Oberfläche passt sich auf Handy, Querformat und Desktop mit derselben logischen Anordnung an.
Wird der Fortschritt automatisch auf ein anderes Gerät übertragen?
Nein. Gespeichert wird derzeit nur im lokalen Browserspeicher. Ein anderes Browserprofil oder Gerät hat daher einen eigenen Fortschritt, solange kein Kontosystem hinzukommt.
