Yukon Solitaire

Yukon Solitaire verteilt das komplette Deck auf sieben Tableauspalten. Bauen Sie absteigende Rot-Schwarz-Sequenzen, bewegen Sie jede geeignete offene Gruppe und vervollständigen Sie vier Farbfundamente ohne Aktie.

SchwierigkeitMittel bis schwer

FähigkeitenPlanung · Räumliches Denken · Konzentrieren Sie sich

Geschichte und Aufgabe

Yukon behält alle 52 Karten auf dem Tisch, lockert jedoch die Gruppenregel: Jede aufgedeckte Karte kann jede aufgedeckte Karte darunter tragen. Diese Freiheit schafft dramatische Enthüllungen, macht aber auch frühe leere Kolumnen wertvoll.

Das Spiel belohnt das schnelle Aufdecken verdeckter Karten und die Entscheidung, wann ein flexibler Gruppenzug eingesetzt werden soll und wann ein Königslandeplatz erhalten bleiben soll.

Spielregeln

Das Tableau besteht aus sieben Spalten mit einem verdeckten und einem offenen Abschnitt. Erstellen Sie absteigende Sequenzen mit wechselnden Farben.

Im Gegensatz zu FreeCell oder Klondike kann jede offene Karte einen Zug mit allen darunter liegenden offenen Karten beginnen, auch wenn diese Gruppe keine vollständige Sequenz darstellt.

Leere Spalten akzeptieren nur einen König oder eine Gruppe, die mit einem König beginnt. Die Fundamente werden je nach Farbe von Ass bis König aufgebaut.

Es gibt keinen Bestand. Der Hinweis hebt einen legalen Zug hervor und „Rückgängig“ stellt das komplette Tableau und den Grundzustand wieder her.

So wird gespielt

  1. Wählen Sie eine aufgedeckte Karte oder eine offene Gruppe aus.
  2. Bewegen Sie es auf den nächsthöheren Rang der entgegengesetzten Farbe oder legen Sie eine einzelne geeignete Karte auf sein Fundament.
  3. Legen Sie verdeckte Karten frei, indem Sie ihre Deckkarten abräumen.
  4. Verwenden Sie eine leere Spalte nur, wenn eine vom König geführte Gruppe sie belegen kann.
  5. Vervollständigen Sie alle vier Anzugfundamente, um zu gewinnen.

Tipps

  • Legen Sie verdeckte Karten frei, bevor Sie nur oberflächliche Änderungen vornehmen.
  • Behandeln Sie eine leere Spalte als King-Reserve und nicht nur als freien Speicherplatz.
  • Verwenden Sie beliebige offene Gruppen, um versteckte Karten aufzudecken, lassen Sie jedoch keine nützliche untere Karte liegen.
  • Verschieben Sie Asse und Karten mit niedriger Basis, wenn sie eine Spalte öffnen oder eine verdeckte Karte entsperren.
  • Verwenden Sie „Rückgängig“, um eine fette Gruppenbewegung mit einer langsameren Offenlegungsroute zu vergleichen.

Fortschritt und Schwierigkeit

Bei jedem Deal werden alle 52 Karten auf dem Tableau verwendet und es gibt keine Stock-Phase.

In den ersten Runden lernen Sie den Unterschied zwischen dem Verschieben einer Sequenz und dem Verschieben einer offenen Gruppe.

Eine größere Herausforderung besteht darin, den Landeplatz zu erhalten und mehrere Enthüllungen im Voraus zu planen.

Hinweis zur Gestaltung

Yukon teilt die Card Engine, das reaktionsfähige Kampf-Canvas, die ursprüngliche visuelle Sprache der Karte, die Touch- und Maussteuerung, das Tutorial, den Hinweis, das Rückgängigmachen und die Tonvorlieben mit dem Rest des klassischen Solitaire-Sets.

Hinweis für Familien

Yukon Solitaire ist ein allgemeines Kartenstrategiespiel, das für Kinder ab 9 Jahren und zum Spielen mit der Familie empfohlen wird. Es ist kein Konto erforderlich. Die Einstellungen bleiben in diesem Browser erhalten.

Häufige Fragen

Gibt es eine Aktie?
Nein. Alle 52 Karten beginnen auf dem Tableau.
Kann jede offene Gruppe umziehen?
Ja. Jede aufgedeckte Karte darf jede aufgedeckte Karte darunter tragen.
Was kann eine leere Spalte füllen?
Ein König oder eine Gruppe, deren erste Karte ein König ist.
Wechseln sich Tableau-Anzüge ab?
Ja. Tableau-Builds werden in wechselnden Farben nach Rang absteigend abgesetzt.
Kann ich es rückgängig machen?
Ja. Durch „Rückgängig“ werden das vollständige vorherige Tableau und die Grundlagen wiederhergestellt.
