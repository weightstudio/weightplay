Yukon Solitaire

Decke Karten auf und baue vier Ablagen nach Symbol vom Ass bis zum König.

Spielanleitung

  1. Wähle eine offene Karte und verschiebe alle Karten darunter mit, auch wenn die Gruppe unsortiert ist.
  2. Lege sie auf eine um einen Rang höhere Karte der anderen Farbe. Eine leere Spalte darf nur eine Gruppe mit König beginnen.
  3. Lege freie Endkarten nach Symbol vom Ass bis zum König ab. Es gibt keinen Nachziehstapel; aufgedeckte Karten öffnen neue Möglichkeiten.

Tipp zeigt einen Zug; Rückgängig nimmt ihn zurück. Neustart wiederholt die Verteilung; Neues Spiel mischt neu.

Häufige Fragen

Gibt es einen Nachziehstapel?
Nein. Alle 52 Karten liegen von Anfang an im Tableau.
Kann jede offene Gruppe bewegt werden?
Ja. Wenn die erste Karte regelgerecht passt, nimmt sie alle offenen Karten darunter mit.
Was darf eine leere Spalte füllen?
Nur ein König oder eine Gruppe, die mit einem König beginnt.
Wechseln sich die Farben im Tableau ab?
Ja. Das Tableau wird absteigend mit wechselnden Farben aufgebaut.
Kann ich einen Zug rückgängig machen?
Ja. Rückgängig stellt den vorherigen Zustand von Tableau und Ablagen vollständig wieder her.
