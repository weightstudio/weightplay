六角排序

Hexa Sort 是一個確定性堆疊謎題，具有 30 個手工製作的階段和無盡的得分模式。將提供的一疊放在開放的六角形上，然後觀察相鄰匹配的頂部顏色組合，直到板變得穩定。

難度容易挑戰
預估遊玩時間2-10分鐘
練習能力規劃 · 配色 · 空間推理

世界與任務

每個階段都從編寫的安排、目標、移動預算和堆疊報價序列開始。早期的戰役在冰凍細胞、寶石、封閉空間、彩虹碎片、炸彈和混合目標出現之前教授乾淨的色彩規劃。

無盡模式會移除戰役目標，並不斷增加顏色和特殊瓷磚壓力，直到沒有合法的開放六角形剩餘。

遊戲系統

只有位於堆疊頂部的連續匹配運行才能移動。較低的顏色保持隱藏狀態，直到其上方的圖層離開或清除。

自動移動是確定性的：解析器傾向於明確且有用的目標，保持轉移相鄰，並避免重新訪問相同的棋盤狀態。

十個匹配的碎片一起清除並顯示下一個顏色。凍結的堆疊從相鄰的位置解凍，寶石從相鄰的活動中收集，特殊的籌碼在同一鎖定回合內解析。

托盤始終提供三疊。放置是最終的，因此在選擇六角形之前請檢查可見的頂部顏色和較低的層。

玩法說明

  1. 選擇 30 個階段之一，或從主線開始無盡。
  2. 選擇提供的三個堆疊之一。
  3. 點擊一個開放的六角形以放置完整的堆疊。
  4. 在計劃下一個放置之前，讓每個相鄰的合併和清除完成。
  5. 在移動預算內完成顯示的目標，或在無盡中繼續得分，直到棋盤填滿。

策略提示

  • 優先選擇集中一種頂部顏色而不密封每個開放六角形的位置。
  • 在提交之前計算一條鏈可以顯示多少個匹配籌碼。
  • 為尷尬的托盤堆保留多個有用的著陸區域。
  • 將冷凍細胞、寶石和目標視為同一計劃的一部分，而不是只追逐最大的可見堆疊。
  • 當兩個合併方向看起來相等時，請考慮接下來要曝光哪種較低的顏色。

關卡與難度成長

階段 1-10 使用十種不同的開局輪廓，並教導放置、上跑和十籌碼清除。

中間階段增加了冷凍細胞、石頭、寶石、彩虹碎片、炸彈、顏色目標和更嚴格的移動限制。

第 26-30 階段在五色壓力下組合了多個系統。無盡模式會不斷增加壓力，並將最好的分數儲存在這個瀏覽器中。

開發設計理念

晶片傳輸使用持久可見層和順序可讀運動。董事會一次解決一項確定性交易，而階段選擇器則回收九張穩定卡，以便長期活動保持順利，而無需在每個階段建立永久專案。 The complete interface uses one centered logical layout with a 920-pixel maximum. Phone, landscape, and desktop views scale the same controls, hit areas, artwork, and game coordinates together instead of stretching individual pieces. Touch, mouse, and keyboard therefore act on the same legal state. The Main poster and Start Game action remain separate from Stage management, while Stage selection, Battle, dialogs, and Result keep their own bounded content and return path.

常見問題

包括幾個階段？
有 30 個手工製作的戰役階段以及無盡模式。
放置堆疊後我可以移動它嗎？
不，請謹慎選擇；排名是最終的，匹配的熱門排名會自動解決。
哪些籌碼可以動？
只有一疊頂部的連續一串相同顏色可以移動到相鄰的一疊。
顏色什麼時候變清晰？
當連接的已解析堆疊達到十個匹配晶片時，該堆疊將被清除。
無盡是隨機的嗎？
報價各不相同，但規則和每個合併決策都是根據當前狀態確定的。
進度保存了嗎？
活動解鎖、無盡的最佳得分和首選項都儲存在該瀏覽器中本地。
Which controls and screen sizes are supported?
The same rules support touch, mouse, and keyboard where the game uses those inputs. The interface scales as one logical layout across the required phone, landscape, and desktop viewports.
Can progress move automatically to another device?
No. This game currently saves to local browser storage only, so another browser profile or device begins with its own separate local progress unless a future account system is added.
