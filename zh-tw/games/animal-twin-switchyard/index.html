Twin Switchyard

Twin Switchyard 是一款原創的同步平台拼圖。引導水獺和山羊穿過分道，翻轉訊號門，並將每個中繼碎片收集在一起。

世界與任務

兩個路線守護者共享一條信號線：水獺負責低車道，而山羊則負責高車道。每個開關站都要求兩名旅客在同一時刻移動，不留下任何一人。

遊戲系統

這兩個角色從一個共享輸入中前進。向左和向右移動兩個旅行者穿過各自的車道，而跳躍則給兩個旅行者一個定時的跳躍。大門可以打開一條車道並關閉另一條車道，因此有用的路線始終是協調問題而不是單獨運行。

僅當正確的旅行者到達中繼碎片時才會收集它們。危險碰撞會重置目前階段的嘗試，同時通過每個碎片和出口的乾淨路線會前進到結果。階段進度和本地最佳移動計數保留在此瀏覽器中。

玩法說明

  1. 從 Stage 選擇已解鎖的關卡；進入 Battle 前先閱讀路線規則與危險預覽。
  2. 使用向左和向右或螢幕上的控制項將兩個旅行者對齊，然後使用跳躍來清除標記的危險。
  3. 觀察門的顏色，讓兩個旅行者朝著自己的中繼碎片移動；一個角色可能是安全的，而另一個角色仍然暴露在外。
  4. 收集所有碎片並抵達配對出口。碰撞會重置嘗試，通關後會開啟 Result 與下一關。

策略提示

  • 在按下「跳躍」之前，規劃好兩條車道的接下來的兩個位置；一名旅客的安全著陸可能會對另一名旅客造成危險。
  • 在大門附近使用短方向水龍頭，而不是在整個開關場進行變換車道。
  • 一起讀取上、下車道標記。最明顯的碎片並不總是下一個安全的碎片。
  • 當一個階段失敗時，確定哪個旅行者首先到達危險並調整共享時間而不是改變每一個動作。

關卡與難度成長

六個創作階段以一個清晰的分裂和一個寬容的跳躍開始。後期階段增加了交替的大門、移動的危險、交錯的碎片、更窄的著陸窗口以及需要兩個旅行者一起到達出口的組合。

開發設計理念

Twin Switchyard 在手機、風景和桌面上保持一個邏輯遊戲空間。它的共享移動、特定車道的危險、觸摸按鈕、滑鼠啟動和鍵盤控制解析為相同的狀態，而主、舞台、戰鬥和結果仍然是單獨的螢幕，可以直接返回。 完整介面使用置中的單一邏輯版面，最大寬度為 920 像素。手機、橫向與桌面畫面會一起縮放相同的控制項、點擊區、圖像與遊戲座標，而不會拉伸個別元素。因此觸控、滑鼠與鍵盤都會操作同一個合法狀態。Main 海報與開始遊戲操作和 Stage 管理分開；Stage 選擇、Battle、對話框與 Result 各自保留有界內容與返回路徑。

家長說明

這款通用瀏覽器遊戲沒有帳戶、購買、聊天、排行榜或廣告流程。階段清除、最佳移動計數、語言、聲音和首選項保留在目前瀏覽器設定檔中，並可能在清除網站資料時重設。 你可以不建立帳號直接遊玩。進度會儲存在目前瀏覽器設定檔的本機儲存空間，而不是線上帳號或跨裝置資料庫。清除網站資料、使用私密瀏覽、改用其他瀏覽器或換到另一台裝置，都可能建立獨立存檔或移除現有存檔。只要瀏覽器允許儲存，語言、音效與減少動態偏好就會沿用 WeightPlay 共用控制。任何指南結果都不是醫療、學校或專業評量。

常見問題

兩位旅行者可以獨立移動嗎？
不會。每個輸入都會將兩人移動在一起，因此難題在於共享時間和車道規劃。
門能改變什麼？
可見門規則改變了當時哪條車道是開放的或安全的；在進行跳躍之前閱讀它。
是什麼原因導致階段失敗？
旅行者碰到標記的危險區，或離開可玩路線，就會重置目前嘗試。
進度可以保存嗎？
已通過的關卡與本機最佳步數會保存在此瀏覽器。
支援哪些操作方式與螢幕尺寸？
在遊戲支援的情況下，觸控、滑鼠與鍵盤會使用相同規則。介面會在手機、橫向與桌面所需的畫面尺寸中，以同一套邏輯版面縮放。
進度會自動轉移到其他裝置嗎？
不會。本遊戲目前只將進度儲存在瀏覽器本機，因此其他瀏覽器設定檔或裝置會有各自獨立的本機進度，除非未來加入帳號系統。
