落塊奪冠

先擊敗較弱守衛，再取得皇冠。

戰力10
步數0
關卡1

遊戲指南

古堡與任務

帶領狐狸沿方塊古堡向下奪取皇冠。你決定哪些地板消失，狐狸、守衛與補給便會落在剩下的支撐上。重點是安排安全的交戰順序，不是逐次操控揮劍。強敵、尖刺、鎖住的地板與護盾都可能截斷路線。滿足指定守衛、首領與印記條件後抵達皇冠才算過關。關內戰力只屬於這次挑戰；通關可解鎖下一關並取得重玩徽章。

玩法說明

  1. 選擇已解鎖關卡，先查看整張地圖與下方支撐。
  2. 點相連的同色方塊，讀取路線預覽，再確認消除或取消。
  3. 等待落下與交戰結束，比較新戰力與下一位守衛，再選另一群方塊。
  4. 抵達皇冠後前往下一關或重玩；失誤時可撤銷上一手或重試。

預覽路線，算好戰力，再確認消除。 點相連的同色方塊，整群消除；方塊不會下落或補入。狐狸落地後會走向同平台最近的守衛，同距離先往左。戰力較高才能獲勝並吸收敵方戰力；相等也會輸。 拖曳地圖或使用箭頭查看四周；◎ 回到角色，▦ 查看全圖。這些操作只移動鏡頭，不移動角色。鏡頭隨角色前進，打鬥時停留讓你看清楚。

鑰匙開門、符文解除護盾。先擊敗旗手可消除敵方加成；避開尖刺，完成首領條件再取皇冠。 只有一個戰力數字：武器與晶石直接增加戰力，倍率道具永久乘上當下總戰力。擊敗弱敵後吸收其戰力，平手也會失敗。面對戰力 80 的敵人：(10 + 20) × 3 = 90 能贏；10 × 3 + 20 = 50 會輸。路線預覽只列運算，不直接提供答案。

難度如何變化

第1–4關介紹落下、吸收與落點武器。第5關起要比較加法與乘法順序；分開的平台可能要先放走強敵，再讓狐狸落下。中段加入鑰匙、鏡像路線、護盾符文與相連房間。後段需提前安排數層樓的落點，不能只消除腳下地板。第20關檢查接近方向，第25關有第二階段首領，第30關結合旗手、護盾與依序印記。難度來自固定謎題的組合增加，沒有可選的難度模式。

過關解鎖下一關，依地形與首領條件安排路線。重玩可挑戰不用提示或目標步數徽章；撤銷可還原上一步。 鑰匙會移除整組門，先算好再開門。 先取得對應符文，再迎戰護盾敵人。 算好戰力路線，依序收集符文與封印。

實用技巧

  • 比較兩種順序：先拿+10再×2，比先×2再拿+10多出10戰力。
  • 放下狐狸前先看下一層；有時要讓守衛或補給先落下。
  • 保留必要守衛、補給與皇冠的安全支撐；目標落到尖刺可能直接失敗。
  • 用撤銷比較路線；提示能協助脫困，但無提示徽章需要不用提示通關。

設計筆記

每次消除都是一個可思考的回合。同色群消失後不會補入，因此地形改變會持續影響後續路線。同樣的操作產生同樣的結果，重試是驗證不同順序，不必等待幸運掉落。狐狸接近敵人後自動攻擊；蓄力與接觸動作用來呈現計算結果，不要求反應點擊。鏡頭跟隨下降，也能拖曳、用箭頭或全圖查看畫面外樓層，讓手機維持清楚的局部視野。路線預覽協助計算，但不直接提供通關步驟。

玩家、裝置與存檔

支援觸控、滑鼠及取得焦點的棋盤格鍵盤操作。不需登入，沒有計時或遊戲內付費。每次挑戰約1–3分鐘，難題可花更久。解鎖、徽章、設定與未完成棋局存於此瀏覽器，不跨裝置同步；清除瀏覽器資料可能刪除進度。無法儲存時仍可在當次工作階段遊玩。

進度與未完成的棋局儲存在此瀏覽器；重玩不會清除已解鎖關卡。

古堡常見問題

戰力也是血量嗎？
不是。畫面的數字是攻擊戰力，沒有另一條血量。必須嚴格高於敵方且滿足條件才能獲勝；相等也會輸。獲勝後吸收敵方戰力。
為何狐狸先打敵人，沒有先拿旁邊的道具？
通常優先面對同平台最近且可到達的守衛。只有道具正在狐狸腳下、且該格沒有敵人時，才會優先撿取；守衛距離相同則先往左。
戰力夠高就能忽略護盾與首領條件嗎？
不行。護盾需要對應符文；必要副官、接近方向與印記順序也必須遵守。遇到兩階段首領時，還要擊敗最後形態。
每個守衛都必須擊敗嗎？
只有本關指定目標與仍存活的首領會擋住皇冠；部分側邊守衛可以略過。先看目標顯示與路線。通關解鎖下一關，重玩則可改善徽章。

  • 順序解謎
  • 路線規劃
