雲鉤快遞

Cloudhook Courier 是一款原創動量平台遊戲。引導雲貂穿過極光環，固定在移動的錨上，並將每個包裹運送到燈籠目標。

世界與任務

雲貂信使穿越六條風之路，每件包裹都仰賴乾淨的擺盪、刻意的釋放與安全落地。每條路線都把短程配送變成清楚可讀的時機問題。

遊戲系統

按住繫繩或空格鍵以連接到最近的可見錨點，然後放開以將動量帶入下一個弧線。左、右或輕推控制可在連接和露天時調整飛行。

收集所有包裹並達到燈籠目標以清理舞台。尖峰碰撞或跌落產生失敗結果；清晰的時間和階段解鎖保留在這個瀏覽器中。

玩法說明

  1. 從 Stage 選擇已解鎖的關卡，進入 Battle 前先閱讀錨點路徑、包裹與危險配置。
  2. 使用「向左」和「向右」或觸碰微移控制來調整接近方式，然後在錨點位於範圍內時按住 Tether 或 Space。
  3. 在揮桿的頂部或前側釋放，將動量帶向下一個環；僅當下一條路線可讀時才重新連接。
  4. 收集所有包裹並觸摸燈籠目標。乾淨的交付會打開結果，而碰撞或跌倒會打開重試失敗的結果。

策略提示

  • 提早附著以建立穩定弧線，但要在繩索把你拉到下一條平台線下方前釋放。
  • 揮桿時使用短距離定向輕擊；長時間按住可能會超出下一個錨點或將信使推入尖刺中。
  • 移動的錨揭示了它們的節奏。當感覺路線狹窄時，在投入之前觀看一個完整的週期。
  • 當運行失敗時，一次更改一個發布決策，以便新航班告訴您路線的哪一部分不安全。

關卡與難度成長

六個創作階段以固定錨點和兩個地塊開始。後來的路線增加了風、移動錨、更長的鏈條、更多的包裹和尖峰場，需要更嚴格的釋放時間。

開發設計理念

Cloudhook Courier 在手機、橫向和桌面上保持一個邏輯的遊戲空間。觸控、滑鼠和鍵盤共享相同的繫繩、釋放和微移狀態，而主螢幕、舞台、戰鬥和結果仍然是單獨的螢幕，可直接返回。 The complete interface uses one centered logical layout with a 920-pixel maximum. Phone, landscape, and desktop views scale the same controls, hit areas, artwork, and game coordinates together instead of stretching individual pieces. Touch, mouse, and keyboard therefore act on the same legal state. The Main poster and Start Game action remain separate from Stage management, while Stage selection, Battle, dialogs, and Result keep their own bounded content and return path.

家長說明

這款通用瀏覽器遊戲沒有帳戶、購買、聊天、排行榜或廣告流程。舞台清除、最佳時間、語言、聲音和首選項保留在目前瀏覽器設定檔中，並可能在清除網站資料時重設。 You can play without creating an account. Progress is saved in local browser storage on the current browser profile, not in an online account or cross-device database. Clearing site data, using private browsing, changing browsers, or moving to another device can create a separate save or remove the existing one. Language, sound, and reduced-motion preferences follow the shared WeightPlay controls when the browser permits storage. No guide result is a medical, school, or professional assessment.

常見問題

附著時可以操控方向嗎？
是的。當繫繩帶動擺動時，左、右或輕推控制可調整信差的水平移動。
我該什麼時候釋放？
當下一個錨點、地塊或燈籠線暢通無阻時，在弧的頂部或前側附近釋放。
是什麼原因導致階段失敗？
觸摸尖峰或掉落到路線之外會結束嘗試並開啟失敗結果。
進度可以保存嗎？
已通過的關卡、解鎖內容與最佳時間會保存在此瀏覽器。
Which controls and screen sizes are supported?
The same rules support touch, mouse, and keyboard where the game uses those inputs. The interface scales as one logical layout across the required phone, landscape, and desktop viewports.
Can progress move automatically to another device?
No. This game currently saves to local browser storage only, so another browser profile or device begins with its own separate local progress unless a future account system is added.
