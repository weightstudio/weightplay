世界與任務

一條小型救援路線被藍色冰牆封住。收集每顆莓果，只改變真正需要的障礙，並在漂行者封住缺口前繼續前進。

遊戲系統

使用方向鍵、WASD 或畫面上的方向控制，每次移動一個格子。按空白鍵破壞前方冰牆，按 F 建造短冰牆。

敵人會在你反覆移動後前進。收集所有莓果就能清除房間；碰撞會阻斷路線，並送你進入專注重試。

21–30: 每次成功改冰，漂行者就會移動。 26–30: 收完莓果後，返回起點格。

玩法說明

  1. 選擇章節，讀取莓果數量與路線提示。
  2. 一次移動一格；當藍色冰牆封住下一條有用路線時，使用破冰。
  3. 需要拖延敵人時，使用建造冰牆建立短暫屏障。
  4. 收集所有莓果，再於結果畫面選擇下一房間、重試或返回章節。

策略提示

  • 破冰前先規劃接下來兩格，確認開口真的會形成路線。
  • 收集露出的莓果時，讓敵人留在屏障另一側。
  • 若路線封閉，快速重試並改變破冰順序，不要重複同一路徑。

關卡與難度成長

六個章節、30 個房間從第一次解凍逐步走向分岔路線、漂行者壓力與最後融冰；路線透過可破壞和可建造的冰牆變化，而不是靠隱藏規則。

21–25: 回音冰原. 26–30: 歸途救援. 通關得★，每達成一項目標再得★。 改冰 ≤ 2; 步數 ≤ 46–62.

開發設計理念

冰原迷宮救援是原創網格救援益智遊戲，結合直接的冰牆編輯、確定性的短房間、可見的敵人壓力，以及適用於觸控和桌面的響應式控制。
