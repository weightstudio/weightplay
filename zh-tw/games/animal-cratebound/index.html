世界與任務

魯克斯正逐座修復貨運方舟。必須把每個符文貨箱送到發光碼頭，貨運路線才能重新開放。

遊戲系統

每次移動一格；只有貨箱後方是空格時才能推動。磁力拉取會讓魯克斯後退，並把相鄰貨箱拉進魯克斯原本的位置。

後續章節會加入滑動冰軌、訊號門、連結貨箱與單向風暴輸送帶。每種裝置都有固定且可讀懂的規則。

玩法說明

  1. 從關卡列選擇已解鎖的方舟倉庫。
  2. 第一次推箱前先讀完整條路線，並保留繞到貨箱後方的空間。
  3. 讓每個符文貨箱抵達發光碼頭即可完成倉庫。

策略提示

  • 從碼頭反推最後一次推動的方向。
  • 除非碼頭就在牆邊，否則不要把貨箱推到外牆上。
  • 把磁力拉取留給無法靠一般行走與推動救回的位置。

關卡與難度成長

30 座倉庫分為六章：初次貨運、極地冰軌、訊號甲板、磁力港灣、連結貨箱與風暴方舟。

開發設計理念

每個倉庫都是已編寫且可解決的。撤銷和重新啟動讓玩家可以測試路線，而不會失去通關進度。 完整的介面使用居中的邏輯佈局，最大像素為 920。手機、風景和桌面視圖將相同的控制、點擊區域、藝術作品和遊戲座標一起縮放，而不是拉伸各個部分。因此，觸控、滑鼠和鍵盤作用於相同的合法狀態。主海報和開始遊戲操作與舞台管理保持分離，而舞台選擇、戰鬥、對話和結果保留自己的有限內容和返迴路徑。

常見問題

How many warehouses are included?
There are 30 authored warehouses across six rule chapters.
Can every stage be solved?
Yes. Every warehouse has a verified solution.
What does Pull do?
Pull spends one magnetic charge, moves Rux backward, and draws the adjacent crate into Rux's previous cell.
Does progress save?
Yes. Clears, unlocks, and best results are stored locally in this browser.
Which controls and screen sizes are supported?
The same rules support touch, mouse, and keyboard where the game uses those inputs. The interface scales as one logical layout across the required phone, landscape, and desktop viewports.
Can progress move automatically to another device?
No. This game currently saves to local browser storage only, so another browser profile or device begins with its own separate local progress unless a future account system is added.
