方塊爆破

Block Blast 是一款原創的 8 x 8 空間謎題，包含 30 個編寫的地形任務和無盡的高分模式。放置目前組中的每個固定形狀，清除完整的行或列，並為仍在托盤中等待的形狀保留足夠的開放空間。

練習能力規劃 · 空間推理 · 焦點

世界與任務

戰役由三十個緊湊的謎題任務組成，而不是一張空板的三十個副本。泥土、冰、石頭、寶石、鎖、顏色目標和設定限制組合成不同的規劃問題。

無盡模式會移除任務目標並繼續處理三形狀套裝。其平衡的形狀池包括小型連接器、中等角、長的五單元件、較大的矩形，以及偶爾的 3 x 3 正方形，因此粗心的板最終會耗盡合法空間。

遊戲系統

形狀保持托盤中顯示的方向，放置後無法移動。選擇一個形狀並點擊合法板單元，或將其拖曳到凸起的著陸預覽上。

整行或整列會立即清除。只有清除線路才獎勵積分；單獨放置方塊不會增加分數。

使用所有三種形狀可以得到一個新的固定集。戰役任務還可以要求路線、地形、寶石、顏色或有限設定的目標。一旦未使用的托盤形狀都不符合合法配合，則運行結束。

冰塊在放置的方塊下方仍然可見，直到該線清除為止，而石頭和鎖會阻擋放置。寶石細胞在被覆蓋時會打開相連的鎖。

玩法說明

  1. 選擇「戰役」進行三十個任務，或選擇「無盡」進行一次連續的得分運行。
  2. 選擇板下方的三個形狀之一。
  3. 點擊打開的儲存格或將形狀拖曳到適當的位置。
  4. 完成一行或一列即可清除並得分。
  5. 使用所有三個形狀接收下一組，同時為每個剩餘形狀留出空間。

策略提示

  • 在進行第一次放置之前檢查所有三個形狀。
  • 保留幾個開放區域，而不是完美填充一個角落。
  • 當下一個形狀確保安全時，建置相交的行和列清除。
  • 不要計劃只接收小件；長形狀和偶爾的 3 x 3 正方形是無盡模式的一部分。
  • 在地形任務中，區分必須清除的單元和永遠無法被佔領的石單元。

關卡與難度成長

階段 1-5 介紹生產線目標和乾淨的董事會規劃。

後面的章節會分層泥土、冰、石頭、寶石、鎖、顏色目標、混合目標和更嚴格的設定限制。

玩家選擇創建的棋盤狀態會帶來無盡的難度，而形狀分佈則保證了常規的大塊壓力，而不僅僅是處理硬形狀。

開發設計理念

分數和效果與實際的清線有關。清除光束保持在已完成的行或列​​的中心，碎片從清除的單元格中落下，並且當玩家立即選擇下一個托盤塊時，白色得分增益會出現在清除的區域上，而不會重播。 完整的介面使用居中的邏輯佈局，最大像素為 920。手機、風景和桌面視圖將相同的控制、點擊區域、藝術作品和遊戲座標一起縮放，而不是拉伸各個部分。因此，觸控、滑鼠和鍵盤作用於相同的合法狀態。主海報和開始遊戲操作與舞台管理保持分離，而舞台選擇、戰鬥、對話和結果保留自己的有限內容和返迴路徑。

常見問題

形狀可以旋轉嗎？
不會。每個托盤形狀都會保持其顯示方向。
積分什麼時候增加？
只有完成的行或列​​才獎勵積分；簡單地放置一個形狀不會。
包括幾個階段？
有 30 個編寫的戰役任務以及無限的無盡運行。
冰和石頭有什麼作用？
冰塊在放置的方塊下方仍然可見，直到其線條消失為止；石頭不能被佔用。
為什麼跑步結束了？
當目前托盤中沒有未使用的形狀具有合法位置時，運行結束。
進度保存了嗎？
活動解鎖和偏好設定會本地儲存在此瀏覽器中。
支援哪些控制和螢幕尺寸？
相同的規則支援遊戲使用這些輸入的觸控、滑鼠和鍵盤。此介面可擴展為跨所需的手機、橫向和桌面視窗的一種邏輯佈局。
進度可以自動轉移到另一台設備嗎？
不會。該遊戲目前僅保存到本地瀏覽器存儲，因此另一個瀏覽器配置文件或設備會以其自己單獨的本地進度開始，除非添加未來的帳戶系統。
